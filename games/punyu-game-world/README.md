# ぷにゅ、ゲームに はいっちゃった！

小学1年生向け。ぷにゅシリーズの3作目。ふしぎなゲーム機に吸い込まれたぷにゅが、いたずらっこ「バグバグ」にまぜこぜにされたゲームの世界を、その世界の服に着替えて直していく。iPhone・iPad の横持ち（Safari）向け。

**状態：開発中（トップの「開発中・非掲載」欄から開く）。**

## あそびの流れ

タイトル → オープニング → ひろば（カセットを選ぶ）→ 世界に入るカットシーン（へんしん）→ その世界のタイトル画面 → ステージ1・2 → ボス前のカットシーン → ステージ3（ボス）→ クリアのカットシーン → けっか（★1〜3）→ ひろば。

4つの世界をクリアすると、さいごの「バグバグの まぜこぜ ゲーム」が開く。弾よけ・たたかい・ダンスが1ステージずつ続き、エンディングへ。

| せかい | あそび | ふく | 内容 |
|---|---|---|---|
| ほしふる ワルツ | 弾幕（たまよけ） | ほしの まほうつかい | [STARFALL WALTZ](../starfall-waltz/) の骨格を借りた、ボス戦中心の弾よけ。指で引っぱって動かす。ショットは自動 |
| けんと たからの だいぼうけん | 見下ろし型の冒険 | ゆうしゃ | くさを切ってかぎを探す／ブロックを押してスイッチに乗せる／でかスライム キング。ドット絵ふうの画面 |
| きらめき☆アイドル ステージ | リズム | アイドル | ぷにゅから流れてくる光が、3色のわっかに重なったらタッチ。3曲 |
| びゅんびゅん サーキット | レース | レーサー | 3レーンの道を、左右のタッチでよけて走る。星を拾い、やじるしでダッシュ。ほしっこ・スライム・ポポと競走 |
| バグバグの まぜこぜ ゲーム | 上の3つ | 3つとも | バグバグと弾よけ → たたかい → いっしょにダンス |

## くりかえし遊ぶしくみ

- **ともだち あつめ**：世界ごとの★（最高記録）の合計がふえると、ひろばに ともだちが遊びに来る。★2 ほしっこ／★4 スライム／★6 ポポ／★9 ルナリア／★12 スライム キング。バグバグはエンディングのあと。まだの子は「？」で見えていて、「あと ★いくつ」が出る。
- **まぜこぜ モード**：エンディングのあとに開く。弾よけ・スライムたいじ・リズム・レースの短い遊び（10〜15秒ほど）が8回、毎回ちがう順番と中身で次々に来て、少しずつ速くなる。同じ遊びは続かない。集めた★の合計が記録になり、いちばんの記録がひろばに出る。途中で終わることはない。

## 怖くない・むずかしくない作り

- ゲームオーバー、残機、時間切れはない。結果は ★1〜3 がつくだけで、かならずクリアになる。
- 弾幕：STARFALL WALTZ から「小さな当たり判定（まんなかの光る点だけ）」「かすり」「技の名前のカットイン」「攻撃が終わると弾が星に変わる」を受けついだ。弾は秒速125以下（画面は横960）とおそく、数も少ない。当たっても「ぽよん」とはねて、まわりの弾が星になり、1.6秒は無敵。ボスの攻撃は時間でも終わる。
- 冒険：敵にさわっても、はねかえるだけ。ブロックはレールの上しか動かないので、詰まない。ボスは3回とんだあと目を回し、そのときだけたたける。
- レース：コーンに当たっても、くるっと回って少しおそくなるだけ。かならずゴールでき、順位で★が決まる。
- リズム：「かんぺき」は±0.13秒、「いいね」は±0.36秒。まちがえても何もへらない。1曲めはどこをタッチしても当たる。

## 操作

- 弾幕：画面のどこでもドラッグ（指の動きのぶんだけ動く）／矢印キー・WASD。
- 冒険：画面をさわって引っぱると移動（スティック）、右下の「えいっ」で剣／矢印キー＋スペース。
- リズム：画面の左・まんなか・右をタッチ／← ↓ →（または 1 2 3）。
- レース：画面の左半分・右半分をタッチでレーンを変える／← →。
- カットシーン：タッチで次へ。右上の「とばす」で飛ばせる。
- 右上の ❚❚ で ひとやすみ（つづける／さいしょから／ゲームきに もどる／おと）。

## 構成

ビルド不要。外部のCDN・画像・音声・フォントは使わない（絵は Canvas の図形、音は Web Audio）。画面は 960×540 の1枚のキャンバスで、端末に合わせて拡大する。

- `data.mjs` — 世界・ステージ・地図・譜面の定義
- `core.mjs` — 3つの遊びの中身、評価、セーブ（描画や音に依存しない）
- `core.test.mjs` — `node --test` で実行。画面に出る文字に漢字がないことも確かめる
- `draw.mjs` — ぷにゅ（服つき）、仲間、背景などの絵の部品
- `cutscene.mjs` — カットシーン（1枚ずつの「こましばい」）
- `view.mjs` — 各あそびの画面、タイトル、ひろば、けっか
- `audio.mjs` — 効果音と曲（リズムの曲は譜面から組み立てる）
- `app.mjs` — 進行・入力・画面の切りかえ

セーブは localStorage（`punyu-game-world-v1`）。着せ替えや買い物の要素はない。
