# ぷにゅの きらきらランド

小学1年生向けの横スクロールアクション。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

5つのワールド×3ステージ（各ワールドの3つめはボス）。ステージは順番に開放され、最後のボスのあとにエンディングがある。ゲーム一覧（トップの `index.html`）には、完成するまでリンクを載せない。

## 操作

- タッチ：画面の左半分で ◀ ▶（ボタンの境目で左右を判定。指をすべらせて切りかえ可）、右半分で「ぴょん」。
- 「せってい」→「おまかせ はしり」をオンにすると自動で右へ歩き、「ぴょん」だけで遊べる。
- キーボード：← → / A D で移動、スペース / ↑ / W / Z でジャンプ、Esc / P で一時停止。

## テストプレイ用

URL の末尾に `?debug` を付けると、遊んでいる間だけ画面の下のまんなかにテスト用の欄が出る。

- 位置・速さ・経過時間・fps・ダメージ回数・穴に落ちた回数
- すべてのステージが最初から選べる
- むてき、当たり判定の表示、旗・ゴール前・ボス前へのワープ、fps の切りかえ、保存データの消去
- クリア画面に、クリア時間とダメージなどの記録を表示

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない。

- `core.mjs`：動きと当たり判定（2Dで計算）、ステージの組み立て
- `stages.mjs`：15ステージの地形・しかけ・敵・ボスの配置
- `view.mjs`：three.js による3D表示（ぷにゅ・敵・ボス・ワールドごとの景色は図形の組み合わせで作成）
- `audio.mjs`：効果音と、ワールドごと・ボス戦の BGM（Web Audio で合成）
- `app.mjs`：画面の切りかえ、タッチ・キー入力、保存（localStorage `punyu-kirakira-v1`）
- `core.test.mjs`：`node --test games/punyu-kirakira/core.test.mjs`。ジャンプの高さ、穴からの救出、全15ステージを「おまかせ はしり」＋簡単な自動操作で最後まで進められること（ボスも倒せること）、穴のそばに敵を置いていないことなどを確認
- `vendor/`：three.js（MIT ライセンス）
