# AURELIA — 暁の遺跡

スマートフォン・iPadの縦持ち向け3Dランゲーム。ゲーム一覧には掲載せず、`games/aurelia/` の直接URLで公開。既存のセーブキーと形式を維持。

## 今回の更新

- 単発のランダム障害物を、6種類の短い攻略区間に変更。ジャンプ→スライド→横移動など、次の操作へつながる並びを左右反転・組み替えして配置。
- 道幅いっぱいの低い壁・梁・切れ目には、それぞれジャンプ／スライドが必要。横回避だけでは攻略できない。
- 連続区間の後には障害物のない補給区間。650m・1,450mで祝福、2,500mで秘宝。
- 金色の縁取りがある脇道は任意の挑戦。跳ぶ・くぐる・跳ぶの3連続を成功させると、出口の秘宝が開く。取得で結晶 +30、灯火 +20、3.2秒の自動無敵加速。途中から出口だけに入っても獲得不可。
- 成功を重ねると姿勢・光の軌跡・走行速度が変化。失敗すると勢いが失われ、よろめきと短い減速から立て直す。
- 着地の膝の沈み込み、近接回避の身のひねり、スライドの火花、結晶がランタンに吸い込まれる動き、回復／消耗による炎の変化を追加。
- 影マップを各フレーム更新し、キャラクターと移動する遺跡の影を追従。自動軽量化後、処理負荷が落ち着けば影を再表示する。
- 無敵加速中は実際に障害物を消し、立体の破片を散らす。失敗時は倒れる／落下する動きを見せてから結果へ移る。報酬は結果演出前に保存。
- 通常プレイ中のFLOW等の成功テキストを廃止。音・身体・物体の変化で結果を表現。
- 耐久力の初期値を3にし、灯火の自然消費を緩和。初回は145mまでダメージなし。灯火が減らない導入区間は全周回共通とし、練習終了で不利にならない。

## 操作と保存

左右スワイプでレーン移動、上でジャンプ、下でスライド／急降下。下降中は着地直前のジャンプ入力を短時間保持。共鳴が満ちたら下のボタンで4.8秒の無敵加速。

キーボードは矢印／WASD、Spaceで共鳴、Escで休止。設定から操作ボタンを表示できる。

`localStorage` の `aurelia.save.v1` に結果・所持結晶・4種類の12段階の強化・設定を保存。旧セーブをそのまま使用。設定のJSON書き出し／読み込みで端末やSafari／ホーム画面起動の間を移動できる。閉じたときの走行途中の状態は復元しない。

## 描画

Three.js 0.180.0（MIT、`vendor/LICENSE-three.txt`）。外部CDN不要。既存の生成背景 `assets/temple-sky.webp` を継続使用。DPR上限と影・遠景の省略による自動軽量化、手動の高画質／軽量切替あり。低負荷設定でも主要な衝突・着地・取得の反応は残す。

## ソースと検証

- `courses.mjs`：攻略区間の定義。
- `core.mjs`：衝突、成長、報酬、コース生成。
- `view.js`：3D、キャラクターの反応、光、粒子、破片。
- `app.js`：入力、画面遷移、保存、演出とロジックの接続。
- `audio.js`：足音、擦過音、衝突音、取得音、環境音楽。

`node games/aurelia/core.test.mjs`
`node games/aurelia/view.test.mjs`

旧セーブ、強化支払い、全レーン障害物の成功／ダメージの重複防止、着地イベント、減速、初回保護、破壊、脇道報酬の条件、80シードのコース生成、30/60Hzでの攻略を確認。最大装備で失敗を含む走りが先へ進めることも比較する。Three.jsを使った描画ロジック試験では、有限な変換行列、自動画質での影の復帰、手動品質設定、演出の後片付けを確認する。

実ブラウザでの操作・画面確認はユーザーが行う方針。iPhone/iPad実機の反応の見え方、滑らかさ、面白さの評価は未確認。
