# AURELIA — 暁の遺跡

スマートフォン・iPadの縦持ち向け、3Dラン＆成長ゲーム。
GitHub Pagesで `games/aurelia/` を開く。外部CDNやビルド処理は不要。

## 遊び方

- 左右スワイプ：3レーンを移動。上：ジャンプ。下：スライド／空中で急降下。
- 低い金色の壁・足場の切れ目はジャンプ、高い石柱は横回避、青緑色の梁はスライド。
- 灯火は時間とともに減少。青い灯りは +12、ジャンプ／スライドで障害物を越えると +5。
- 結晶、華麗な回避、直前の横回避で共鳴がたまる。ボタンを押すと4.8秒の無敵加速。
- 650m・1,450mでは灯火 +35、耐久力 +1。3種類の祝福から1つを選択。2,500mでクリア。
- 結晶と距離報酬で4種類の装備を12段階ずつ強化。失敗しても報酬を持ち帰れる。
- 初回の190mは灯火消費とダメージを免除する練習区間。
- キーボードは矢印／WASD、Spaceで共鳴、Escで休止。操作ボタンの表示も設定できる。

## 保存・端末対応

`localStorage` の `aurelia.save.v1` に結果と永続強化を保存。
Safariとホーム画面起動の間、または別端末へは、設定のJSON書き出し／読み込みを使用する。
タブ移動・画面ロックで自動休止。閉じたときの探索途中の状態は復元しない。
通常はDPR上限1.5、遅いフレームが続くと影を省略しDPR1に変更。高画質／軽量の手動切替あり。
画面はdynamic viewportとsafe-areaを使用し、スワイプ中のスクロール・選択・拡大を抑止する。

## 構成

- `core.mjs`：生成、衝突、灯火、報酬、強化の純粋なゲームロジック。
- `view.js`：Three.jsの3D描画、アニメーション、光と影、霧、粒子。
- `app.js`：入力、画面遷移、保存、サウンドと描画の接続。
- `audio.js`：Web Audioで生成する効果音・環境音楽。
- `assets/temple-sky.webp`：このゲーム用に生成した背景美術。
- `vendor/`：Three.js 0.180.0（MIT、同梱ライセンス参照）。

背景生成：built-in image generationを使用。プロンプト要旨は、縦長2:3、雲上の巨大な金色の環状神殿、滝の流れる浮遊遺跡、深い青緑と朝焼けの金色、実写的な材質と空気遠近法、手前の3Dコースを重ねるため下部は霧、人物・文字・UIなし。

## 検証

`node games/aurelia/core.test.mjs`

保存値の正規化、強化の支払い、障害物ごとの衝突、練習中の保護、共鳴、祝福、報酬の二重加算防止、120シードのコース生成、5シードの走行方針比較を検証する。
全ての障害物列には安全なレーンがあり、隣接列間は最低24m。最大速度でも約1.28秒の間隔を確保（共鳴中は無敵）。
実ブラウザの操作・画面確認はユーザーが行う方針。iPhone/iPad実機の滑らかさと操作感は未確認。
