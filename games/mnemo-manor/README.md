# 記憶の館（仮題：Mnemo Manor）

依頼の品を自分の「記憶の館」に置いて覚え、暗闇の迷宮をランタンの一瞬の光で進み、祭壇で正しい品を順番どおりに選び取るローグライト。企画と制作意図は [DESIGN.md](DESIGN.md)。

完成するまでトップの `index.html` からはリンクしない。確認は直接リンク（`games/mnemo-manor/`）で行う。

## いま遊べるところ（DESIGN.md 11章の M1〜M4 相当）

1. **依頼の掲示板**：4枚の依頼（2〜4品）から何件受けるかを選ぶ。受けた品の合計が館の置き場の数まで。2件で ×1.15、3件で ×1.3 のお礼。いまの腕前の「おすすめ品数」も出る
2. **館への収納**：品物を道順どおりに置き場（家具）へドラッグ（またはタップ）。置くと家具との奇妙な場面が起きる（例：「ヨーヨーが大扉をノックしたら、中からもう一つ出てきた」）。置き終わったら館をひと回りして確かめ、依頼書を燃やして潜る。砂時計の4割以上を残して潜るとランタン油 +1
3. **潜行**：閃光の部屋（M0 の閃光。1〜2部屋）を抜けると祭壇。祭壇では「3品目は？」と聞かれ、候補から選ぶ。まちがえるとミミックに油を食われる。答えのあとに、館のどこでどんな場面だったかを見せる
4. **記憶の灯**：祭壇でその品を置いた部屋を2秒だけ覗ける（その品のお礼は半分）
5. **精算**：思い出した品・依頼のお礼・閃光で見つけた宝を金貨に
6. **館の手入れ**：金貨で部屋を増やす（置き場 +4。玄関・居間・台所から始まり、書斎・浴室・寝室・温室・屋根裏まで）、油壺、記憶の灯。閃光の表示時間を延ばす強化は作らない

まだ入れていないもの：預かり依頼（M5）、順番指定の依頼、家具を選ぶ模様替え、反響の部屋、計測モード（M7）。

## 適応難易度

- 閃光：3-down 1-up の階段法を、表示時間／周辺対象の距離／妨害物の数で独立して持つ。表示時間は 500ms から 0.8 倍ずつ、下限はその端末の1フレーム。段階（1：紋章だけ → 2：＋宝箱の方向 → 3：＋コウモリ・偽の宝箱）は直近の成功率で上下する
- 祭壇：ダミーの紛らわしさを階段法で上げる（0：候補3つ・違うカテゴリ → 1：同じカテゴリが混ざる → 2：依頼の別の品が混ざる → 3：候補5つ）。記憶の灯を使った回は動かさない
- 品数：全部思い出せたらおすすめ +1、6割未満なら −1（最小3、最大は館の置き場の数）
- 数値はプレイヤーに見せない。ランタンの炎の大きさと部屋の暗さで伝える

## 表示時間の精度（DESIGN.md 10.3）

- `setTimeout` は使わず、`requestAnimationFrame` のフレーム数で表示する。収納のあいだに実際のリフレッシュレートを測る
- 閃光とマスクの絵は注視点のあいだに別の canvas に描いておき、本番のフレームでは `drawImage` 1回だけ
- 1回ごとに、狙った時間・フレーム数・実測・フレーム落ちの有無を記録。フレーム落ちした回は階段を動かさない
- 閃光の途中で画面が隠れたり大きさが変わったりしたら、その回は採点せずにやり直す。閃光の最中は効果音を鳴らさない

## 操作

- 収納：品物のカードを光っている置き場へドラッグ（光っている置き場をタップしても置ける）。ひと回りでは ◀ ▶ で部屋を移り、置き場をタップすると場面をもう一度見られる
- 閃光：中央の2×2が紋章、まわりの8つが方向。キーボードは `1`〜`4` で紋章、`Q W E / A D / Z X C`（テンキー・矢印キー）で方向
- `Esc` またはHUDの ✕ でランをやめる（金貨はもらえない）

## テストプレイ用

- `?debug`：左下にリフレッシュレート、各階段の段階、直前の閃光の「狙った時間／実測／フレーム落ち／反応時間」。段階1〜3の切りかえとログの JSON 保存ボタンもある
- `?seed=123`：乱数を固定
- 「せってい」から記録の書き出し・読みこみ（JSON）、おとな／こどもの切りかえ（こどもは砂時計なし、祭壇は紛らわしさ1まで、閃光は 800ms から）

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部の CDN・画像・音声は使わない（品物と家具は絵文字）。
DESIGN.md 10.1 の案は TypeScript＋Vite だが、このリポジトリはどのゲームもビルドなしで GitHub Pages に置いているので ES モジュール（`.mjs`）で書き、フォルダ構成とロジック／描画の分離は 10.2 に合わせている。

```
config/tuning.mjs            調整用の数値（プロフィール、階段法、報酬、館の手入れの値段）
content/items.mjs            品物（40種、5カテゴリ）
content/palace.mjs           部屋（8部屋×置き場4）と家具ごとの相互作用（各3通り）
content/clients.mjs          依頼人
core/rng.mjs                 seed 付き乱数
core/adaptive/staircase.mjs  階段法
core/flash/flash.mjs         閃光の1回の生成・判定・難易度の更新
core/palace/palace.mjs       館の道順と置き場、場面の文
core/run/requests.mjs        掲示板の依頼
core/run/run.mjs             ラン（部屋の並び、祭壇の候補、油、精算、おすすめ品数）
core/save/save.mjs           保存（localStorage `mnemo-manor-v1`）、書き出し・読みこみ
render/                      閃光の描画（2D canvas）、リフレッシュレートの計測、紋章・宝箱の絵
ui/room.mjs                  館の部屋と相互作用アニメーション（DOM）
ui/store-view.mjs            収納
ui/altar-view.mjs            祭壇・記憶の灯・答え合わせ
ui/screens.mjs               掲示板、館の手入れ、精算
ui/answer-pad.mjs            閃光の回答ボタン
audio.mjs                    効果音（Web Audio で合成）
app.mjs                      画面の切りかえ、ランの進行、閃光のフレーム単位の進行
tests/core.test.mjs          node --test games/mnemo-manor/tests/*.test.mjs
```
