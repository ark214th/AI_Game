# まもれ！キングダム

王国の おしろを 守る タワーディフェンス。小学3年生むけ（字は 小3までの 漢字）。

- 右上の 門から 道ぞいに 来る まものを、タワーと ヒーローで たおす。おしろは 左下。
- **バトル中の お金＝ゴールド**：タワーを おく／強化する。レベル3で 2つの 道に 進化（レベル5まで）。
- **持ち帰る お金＝ほう石**：勝っても 負けても もらえ、まちの おみせで ずっと のこる 買いものが できる。
  1. タワーの 強化（安い）　2. 新しい タワー（中くらい）　3. ヒーロー（高い）　＋ おしろの 強化
- ステージ3つ（草原・雪山・火山）× むずかしさ3だん ＋ はてしないモード。
- ゲームオーバーで 何かを うしなうことは ない（負けても ほう石が ふえる）。

## つくり

| ファイル | やくわり |
|---|---|
| `data.mjs` | タワー・てき・ヒーロー・ステージ・ねだんの 数字、波の 作りかた |
| `core.mjs` | ゲームの 計算（がめんに さわらない）。バトル・おみせ・ほぞんデータ |
| `draw.mjs` | え。ぜんぶ Canvas の 図形（がぞうファイルなし） |
| `audio.mjs` | こうかおんと BGM（Web Audio） |
| `app.mjs` | がめんの きりかえ・タップそうさ |

ビルド不要・外部ファイルなし。ほぞんは `localStorage`（`mamore-kingdom-v1`）。

## 確認

```
node --test games/mamore-kingdom/*.test.mjs
```

- `core.test.mjs`：ルールの テストと、自動プレイでの バランス確認（はじめてでも 草原は 勝てる／雪山は 買いものを すると とどく／ぜんぶ 買えば 火山の「むずかしい」に 勝てる）。
- `text.test.mjs`：がめんの 字が 小3までの 漢字だけか。

バランスを 変えるときは `data.mjs` の 数字を なおして、上の テストを 回す。
