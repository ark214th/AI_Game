# ぷにゅの がっこう

小学1年生向けの「学校生活シミュレーション」。ぷにゅが『ふしぎな ペットホテル』のお客さんたちと同じクラスで、**げつようびから きんようびまでの1週間**を過ごす。ゴールは金曜日の **ダンス はっぴょうかい**。iPhone・iPad の横持ち（Safari）向け。

**状態：開発中（トップの開発者モード「開発中・非掲載」から遊べる）。**

## いきさつ

- お子さんの要望（2026-11-18）：「シミュレーションゲーム」「ぷにゅが学校へ行く」「ぷにゅホテルのお客さんがクラスメート」「家に家具を飾れる」。保護者の方の見立ては「ふだんの生活をシミュレートしたい」。好きな教科は おえかき・工作・ダンス。
- おためしばん（1日だけ、#51）の感想（2026-11-19）：大喜びで、セリフを大声で朗読しながら遊んだ。いちばん好きなのはダンス（テレビでダンスが始まると一緒に踊る子）。おはなしがあるのが好き。なわとびが難しかった（#52 で直した）。
- そこで、ダンス はっぴょうかいに向かう1週間のおはなしにした。

## 1週間のおはなし（`story.mjs`）

| ようび | じゅぎょう | やすみじかん | できごと |
|---|---|---|---|
| げつ | おえかき・ダンス「きらきら ステップ」・こうさく | おにごっこ／なわとび | はじめての がっこう。帰りの会で「きんようびに ダンス はっぴょうかい」の お知らせ |
| か | さんすう・ダンス「ぽっぷん ジャンプ」（はやい）・おえかき「はっぴょうかいの ポスター」 | かけっこ／なわとび | きららの おたんじょうび（給食にケーキ）。ポスターは体育館の舞台に貼られる |
| すい | こくご・こうさく「いしょう づくり」・ダンス「ぷにゅぷにゅ ダンス」の前半 | おにごっこ／かけっこ | ぽかりが はさみを忘れて、ぷにゅが貸す。ちゃぷが「おどれるかな…」と落ちこむ |
| もく | おんがく（けんばんハーモニカ）・たいいく（かけっこ）・リハーサル | **ちゃぷと ダンスの れんしゅう**／おにごっこ | ちゃぷが自信をつける |
| きん | リハーサル（前半）→ きゅうしょく → **はっぴょうかい** | なわとび／かけっこ | ペットホテルのみんな（どらりん ほか）が見に来る。帰ったら クラス全員が ぷにゅの家で おいわい |

毎日の流れ：あさ（起こす → きがえ → じかんわりを見てランドセル）→ とうこう（日替わりの友だちと）→ あさの かい → 1じかんめ → やすみじかん → 2じかんめ → きゅうしょく（日替わりの こんだて）→ 3じかんめ → かえりの かい → かえりみち → ほうかご（へやを かざる → 友だちが来る）→ ねる → **にっき**（その日のことが文になって残る）→ つぎの ひ。

金曜日のにっきのあとは「ぷにゅの 1しゅうかん おしまい」（5日分のにっきを並べる）→ タイトル。クリア後はタイトルで好きな曜日を選んで遊べる。途中でやめても、タイトルの「つづきから（○ようび）」で続きの曜日から始まる。

## あそび

- **ダンス（リズム）**：上から光が降りてきて、ボタンに重なったらタッチ。4つのポーズ（ばんざい・ひだり・みぎ・くるり）。曲は4つ（`data.mjs` の `SONGS`：きらきら ステップ 100BPM／ぽっぷん ジャンプ 112BPM／ぷにゅぷにゅ ダンス 104BPM・24小節／けんばん ドレミ 96BPM・2ボタン）。同じしくみで、ダンス・おんがく（「ド」「ソ」の けんばん）・リハーサル（舞台・いしょう）・ちゃぷとの れんしゅう（校庭）・はっぴょうかい（舞台・ライト・観客・ポスター・いしょう）を作っている。★0 は「もういちど」（2回目からは先へ進める）。はっぴょうかいは最後まで踊ればはなまる（★1以上）で、終わると拍手。
- **おえかき**：指で描く（10色・太さ3・けしゴム・スタンプ3種）。絵は家の壁に飾られる。かようびの絵は「ポスター」として はっぴょうかいの舞台に貼られる。
- **こうさく**：はこ・かみコップ・ねんど に色と部品（12種）を付ける。家に飾られる。
- **いしょう づくり**：ぼうし6種・マント6色・むねの かざり4種。リハーサルと はっぴょうかいで着る。
- **さんすう「かぞえっこ」**：絵を数える問題3つ＋たしざん2つ（こたえは10まで）。数字のボタンから選ぶ。
- **こくご「ひらがな あて」**：絵と、1字だけ空いたことば（りんご・さかな など20語）。3つの ひらがなから選ぶ。
- **かけっこ**：画面をどんどんタッチして走る（1秒に4回くらいで1位）。
- **なわとび**：黄色い輪が縮んで足元に着いたらタッチ。縄が通ってから0.14秒までは遅れてもセーフ。
- **おにごっこ**：指でぷにゅを動かして、逃げるぽかりに3回タッチ。
- **きゅうしょく**：日替わりの こんだてを タッチして食べる。
- **へやの かざりつけ**：もらったシールで家具を買う（25種、2〜8まい）。壁紙・床も選べる。来た友だちは好きなもの（ペットホテルの「すきな しるし」）があると大喜び。

失敗しても怖くない作り：まちがえたボタンが灰色になって選び直せる、ひっかかってもすぐやり直し、★0でも2回目からは先へ進める。

## シール

授業や遊びのたびにもらえる（同じ日に遊び直しても増えすぎない）。1日でだいたい 10〜15まい。

## 確認のしかた

- `node --test games/punyu-gakkou/core.test.mjs`
- URL に `?debug&scene=dance&day=2` などを付けると、その曜日のその場面から始まる（場面：`title / morning / walk / classHello / draw / recess / tag / rope / race / pair / dance / music / rehearsal / recital / math / kokugo / costume / lunch / craft / classBye / home / diary / ending / period`）。`&stickers=12` でシールを持った状態にできる。`&auto` を付けるとダンス系となわとびが自動で成功する（テスト用）。

## 構成

ビルド不要。外部のCDN・画像・音声は使わない（音は Web Audio で合成、絵は図形）。キャラクター・家具・かべ紙の絵は `../fushigi-pet-hotel/draw.mjs` と `data.mjs` をそのまま読み込んで使う（見た目をそろえるため）。

- `story.mjs`：1週間の じかんわり・やすみじかん・こんだて・セリフ（朝・登校・朝の会・給食のあと・帰りの会）
- `data.mjs`：クラスメート・もちもの・ダンスの曲（譜面と音楽）・工作の部品・おみせ
- `core.mjs`：保存データの整形、1週間の進み、にっき、部屋の家具、ランドセル、ダンスの譜面と判定、なわとび・かけっこ、さんすう・こくごの問題、いしょう、工作
- `ui.mjs`：キャンバス（たて640の座標）・ボタン・会話の窓・きらきら・画面の切りかえ
- `art.mjs`：教室・校庭・体育館・音楽室・舞台と観客・まち・学校・ぷにゅの家と部屋・工作・いしょう
- `app.mjs`：1日の予定（`G.day.plan` を `G.next()` で進める）、タイトル・あさ・みち・朝の会・帰りの会・チャイム・給食・にっき・1週間のおわり
- `lessons.mjs`：おえかき・やすみじかん（おにごっこ・なわとび・かけっこ）・リズム（ダンス・おんがく・リハーサル・れんしゅう・はっぴょうかい）・こうさく・さんすう・こくご・いしょう
- `home.mjs`：ほうかごの部屋（かざる・友だちが来る・金曜はみんなで おいわい・ねる）
- `audio.mjs`：効果音・学校のチャイム・BGM（あさ／がっこう／よる）・ダンスの曲・けんばんハーモニカ・拍手
- 保存：localStorage `punyu-gakkou-v1`（おためしばんの保存データもそのまま読める）
