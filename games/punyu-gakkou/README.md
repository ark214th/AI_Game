# ぷにゅの がっこう（おためしばん）

小学1年生向けの「学校生活シミュレーション」。ぷにゅが、『ふしぎな ペットホテル』のお客さんたちと同じクラスで1日を過ごす。iPhone・iPad の横持ち（Safari）向け。

**状態：開発中（トップの開発者モード「開発中・非掲載」から遊べる）。** お子さんの感想を聞くための「おためしばん」で、1日（朝〜夜）遊ぶと「おためしばんは ここまで！」になる。

## なぜ作ったか

お子さんの要望（2026-11-18）：「シミュレーションゲーム」「ぷにゅが学校へ行く」「ぷにゅホテルのお客さんがクラスメート」「家に家具を飾れる」。保護者の方の見立ては「ふだんの生活をシミュレートしたい」。好きな教科は **おえかき・工作・ダンス** なので、この3つを授業の見せ場にした。

## おためしばん おわり の画面

- その日の思い出（絵・ダンスの★・工作・遊んだ友だち）を並べる。
- 「いちばん たのしかったのは どれ？」を6つから選んでもらう（おえかき／ダンス／こうさく／やすみじかん／きゅうしょく／へやの かざりつけ）。選んだものは端末に保存（`feedback`）。
- 「タイトルへ」→「もういちど あそぶ」で、また1日目を遊べる。部屋・シール・絵・工作は残る。

## シール

おえかき 3／やすみじかん 2／ダンス 1＋★の数／きゅうしょく 1／こうさく 3（1日で 10〜13まい）。同じ日に遊び直しても増えすぎない。家具は 2〜5まい。

## 確認のしかた

- `node --test games/punyu-gakkou/core.test.mjs`
- URL に `?debug&scene=dance` などを付けると、その場面から始まる（`title / morning / walk / classHello / draw / recess / tag / rope / dance / lunch / craft / classBye / home / end / period`）。`&stickers=12` でシールを持った状態にできる。`&auto` を付けるとダンスとなわとびが自動で成功する（テスト用）。

## 構成

ビルド不要。外部のCDN・画像・音声は使わない（音は Web Audio で合成、絵は図形）。キャラクター・家具・かべ紙の絵は `../fushigi-pet-hotel/draw.mjs` と `data.mjs` をそのまま読み込んで使う（見た目をそろえるため）。

- `data.mjs`：クラスメート・じかんわり・もちもの・給食・ダンスのポーズ・工作の部品・おみせ・感想の選択肢
- `core.mjs`：保存データの整形、部屋の家具（買う・しまう・色）、ランドセル、ダンスの譜面と判定、なわとび・おにごっこの判定、工作、シール
- `ui.mjs`：キャンバス（たて640の座標）・ボタン・会話の窓・きらきら・画面の切りかえ
- `art.mjs`：教室・校庭・体育館・まち・学校・ぷにゅの家・ぷにゅの部屋・工作・クラスメートの絵
- `app.mjs`：タイトル・あさ・みち・朝の会・帰りの会・チャイム・給食・おわりの画面
- `lessons.mjs`：おえかき・やすみじかん（おにごっこ・なわとび）・ダンス・こうさく
- `home.mjs`：ほうかごの部屋（かざる・友だちが来る・ねる）
- `audio.mjs`：効果音・学校のチャイム・BGM（あさ／がっこう／よる）・ダンスの曲
- 保存：localStorage `punyu-gakkou-v1`
