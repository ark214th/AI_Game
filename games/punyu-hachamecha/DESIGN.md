# ぷにゅと はちゃめちゃ おたすけ大冒険 企画メモ

作成日：2026年11月8日

状態：企画（娘のリクエスト）。スペースで作った試作版（マップ＋ミッション3つ）は遊びの検証用とし、本命は本リポジトリで three.js 版を制作する。

想定プレイヤー：小学1年生（6〜7歳）。ひらがな・カタカナが読めるが、文章は読ませない設計にする。

想定環境：iPhone・iPad の横持ち、Safari（ホーム画面に追加して全画面で遊ぶ使い方も含む）。PCのキー操作にも対応する。


## 注文（娘から、2026年11月8日に保護者経由で聞き取り）

- 『ゆめかわ かんじの しま』のような雰囲気の3D画面
- バーチャルパッドでぷにゅを移動させる
- ゲーム世界にはキャラクターがいっぱいいて、話しかけるとミッションがスタート
- 成功すると笑顔になる。どんどんみんな笑顔になっていく
- 文章を読ませるのではなく、アニメーションやエフェクトで感覚的に楽しめるもの（保護者からの補足）


## 目指す体験

**まるいぷにゅが3Dの島を自由に歩き回り、困っている友だちを助けると、その子が笑顔になり、島がどんどん賑やかになっていく。そして島の暮らしは、クリアしたあとも毎日つづく。**

優先順位：

1. **文章を読ませない**：お願いはふきだしの絵（アイコン）で伝える。画面の文字は単語レベルまで、ひらがな・カタカナのみ。
2. **感覚的に楽しい**：ぷにっと弾む動き、キラキラ、紙ふぶき、ハートが飛ぶエフェクト。音はWeb Audioで合成。
3. **失敗が怖くない**：ゲームオーバーなし、時間制限なし、残機なし（きらきらランドの基本を踏襲）。
4. **みんなが笑顔になる達成感**：笑顔カウンターが見え、笑顔が増えるたび島に花・ちょうちょ・飾りが増えていく。


## 遊びの流れ

1. 島（のはら）をバーチャルパッドで探索する。困っている子は、頭の上に「！」マークと、困りごとを絵で表すふきだしを出している。
2. 近づいてタップ（話しかける）と、その場でミッションが始まる。画面遷移は最小限にする。
3. ミッションは「さわる」系の小さなインタラクション（30秒〜1分）。ミニゲーム的なものと、探索・収集系を混ぜる。
4. 成功すると、その子が笑顔になる（表情が変わる＋ジャンプ＋ハートが飛ぶ）。ごほうびに「えがおシール」と「おてがみ」（絵が中心、一言だけ）がもらえる。
5. 全員が笑顔になると花火のエンディング。特別な「にじシール」がもらえる。そのあとも島で自由に遊べる（「遊びごたえの設計」参照）。


## 遊びごたえの設計（目標：通しで約1時間）

5分で終わらせないための工夫。ただし実時間の日替わり（1日ごとに新しい困りごと）は入れない。漢字ゲームのような「学習の習慣づけ」が目的の作品ではなく、純粋なゲームなので、1回〜数回のプレイで達成感まで届く長さにする（2026年11月8日、保護者の判断）。

1. **段階開放**：困っている子は最初から全員分を出さない。まず1〜2人の「こまった」から始まり、助けると次の子が島に来たり、困りごとが発生したりする（ペットホテルの「1匹ずつ来る」方式）。自然にペース配分ができ、島が少しずつ賑やかになる変化も楽しめる。
2. **ミッションの厚み**：各ミッションは移動＋インタラクションで3〜6分ほど。5人分で約20〜30分。
3. **探索・収集の寄り道**：島に「きらきらのかけら」や光るスポットを散らし、ミッションの合間に集めて歩ける。集めるとシール帳の「はっけん」ページが埋まる。
4. **クリア後の自由遊び**：全員笑顔のあとも島でそのまま遊べる。「おかわりミッション」（同じ型の小さなお願いがランダムに出る、任意・無制限）で、終わりはプレイヤーが決める。

目安：本編（全員笑顔まで）で約45〜60分。笑顔の節目で新しい仲間が来る・飾りが増える演出は、段階開放と兼ねて使う。エリア拡張（うみべ等）は v2 候補とし、保存データの形は最初から拡張を見込んで設計する。


## 操作

- 左下：十字キー（バーチャルパッド）でぷにゅを移動。
- 右下：大きなボタン1つ（話しかける／決定／ミッション中のアクションを兼ねる場面が多い）。キャラや光るものは直接タップでも反応する。
- PC：矢印キー／WASDで移動、スペースでボタン。


## v1の範囲

- エリア：のはら1つ。3D表示は three.js、移動と当たり判定は2Dで計算（きらきらランド方式）。
- キャラクター：5人（ゲームにしやすさで選定）。
  - おおきなカニ：じゃんけん【ミニゲーム】手の絵の大きなボタン。回を重ねるごとにカニが少し大きくなる。ぷにゅが2回勝ったら成功。
  - いたずらかぜ：飛ばされた帽子を追いかける【移動＋タップ】島の中を移動しながら帽子を追い、5回タップでつかまえる。
  - くもくもさん：落ちた星集め【探索・収集】エリアに散らばった星を歩いて集める。途中の星は1回逃げる。
  - ちゃぷ：かいがら探し【探索・収集】光るかいがらを3つ探してタップ。
  - ぷるるんゼリー：クリームのせ【ミニゲーム】頭をトントンしてクリームをのせる。
- ごほうび：えがおシール帳、おてがみ。きせかえは長期拡張（v2）とあわせて導入。
- 保存：localStorage（進みぐあい・シール・おてがみ・笑顔の合計・はっけん）。拡張を見込んだ形にする。


## 技術メモ

- ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない。three.js は `games/punyu-kirakira/vendor/` を流用する。
- 構成案：`core.mjs`（移動・ミッション進行の計算）／`area.mjs`（島とキャラの配置）／`view.mjs`（three.js による3D表示）／`audio.mjs`（効果音・BGMの合成）／`app.mjs`（画面切りかえ・入力・保存）／`data.mjs`（キャラ・ミッション・おてがみのデータ）。
- テスト：`node --test` で、全ミッションが最後まで進められること、保存データの読み直し、表示テキストに漢字が混ざっていないことなどを確認する。
- 公開方針：完成までトップの `index.html`（ゲーム一覧）には載せない。URL直打ちで保護者がテストプレイし、OKが出たら一覧にリンクする（従来方式）。


## 残りの相談
