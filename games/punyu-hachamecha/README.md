# ぷにゅと はちゃめちゃ おたすけ大冒険

小学1年生向けの「島めぐり・おたすけ」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

**状態：試作1（開発中・非掲載）。** 島は「おはなの のはら」と「きらきら うみべ」、ともだちは ちゃぷ と おおきなカニ。

3Dの島をぷにゅが歩き、こまっている ともだちに話しかけると、その子ならではの遊びが始まる。成功するとその子が笑顔になってぷにゅについてきて、島に花が咲く。笑顔が増えると もや が晴れて、次の島が見えてくる。失敗・時間制限・ゲームオーバーはない。

## 操作

- タッチ：画面のどこでも、さわって引っぱると移動（スティック）。右下のボタンが光ったら、押すと話しかける（ともだちを直接タップしてもよい）。
- キーボード：矢印キー / WASD で移動、スペースで話しかける。じゃんけんは 1（グー）・2（チョキ）・3（パー）。
- ピンクのちょうちょが、次に行くとよい方へ飛んで案内する。
- 画面の上に「いま する こと」が1行で出る。ともだちとの会話は、画面をタップすると次へ進む。

## あそび

- 🦦 ちゃぷ：かいがらさがし。話しかけるとついてくるので、橋をわたって はまべへ。波が引いたときに出てくる かいがら にふれると拾える。3つで成功。波がいちばん引いたときだけ出る「にじいろの かいがら」を拾うと はなまる が増える。
- 🦀 おおきなカニ：じゃんけん。出す前に、カニの手が「ちらっ」と見える。見抜けば勝てる。3回勝てば成功（まけ・あいこでも続く）。まけが少ないほど はなまる が増える。
- はなまる🌸は1〜3。ごほうびの画面の「もういちど」で、何度でも遊びなおせる。

## 寄り道とごほうび

- きらきらのかけら：2つの島に12個。ふれると集まり、シールちょうの「はっけん」に記録される。
- えがおシール と おてがみ：ともだちを笑顔にするともらえる。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下に保存データの消去ボタンが出る。

## 構成

ビルド不要。外部のCDN・画像・音声は使わない（音は Web Audio で合成、絵は three.js の図形の組み合わせ）。

- `data.mjs`：島・橋・もや・木や岩・ともだち・遊びの数値・シール・おてがみ・かけら
- `core.mjs`：島と橋の上の移動と当たり判定（2Dで計算）、ともだちの状態、かいがら・じゃんけんの進行、はなまる、もや、あんないの道、保存データの整形・検証
- `view.mjs`：three.js による3D表示（three.js は `../punyu-kirakira/vendor/` を流用）
- `audio.mjs`：効果音とBGM（Web Audio で合成）
- `hands.mjs`：じゃんけんの手の絵（図形で描く）
- `app.mjs`：画面の切りかえ、会話、スティックとキー入力、保存（localStorage `punyu-hachamecha-v2`）
- `core.test.mjs`：`node --test games/punyu-hachamecha/core.test.mjs`
