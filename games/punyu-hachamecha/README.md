# ぷにゅと はちゃめちゃ おたすけ大冒険

小学1年生向けの「島めぐり・おたすけ」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

**状態：本編を最後まで実装（開発中・非掲載。保護者のテストプレイ中）。**

3Dの島々をぷにゅが歩き、こまっている ともだちに話しかけると、その子ならではの遊びが始まる。成功するとその子が笑顔になってぷにゅについてきて、島に花が咲く。笑顔が増えると もや が晴れて次の島へ橋がつながる。5人の ともだち を笑顔にして、最後に でかもやもや へ笑顔を届けるとエンディング。失敗・時間制限・ゲームオーバーはない。

島は6つ：おはなの のはら／きらきら うみべ／おかしの もり／ふわふわ くものうえ／ほしぞらの おか／もやもやの おか。

## 操作

- タッチ：画面のどこでも、さわって引っぱると移動（スティック）。右下のボタンが光ったら、押すと話しかける（ともだちを直接タップしてもよい）。
- キーボード：矢印キー / WASD で移動、スペースで話しかける。じゃんけんは 1（グー）・2（チョキ）・3（パー）。
- ピンクのちょうちょが、次に行くとよい方へ飛んで案内する。
- 画面の上に「いま する こと」が1行で出る。ともだちとの会話は、画面をタップすると次へ進む。

## あそび

- 🦦 ちゃぷ：かいがらさがし。波が引いたときに出てくる かいがら にふれると拾える。3つで成功。「にじいろの かいがら」で はなまる が増える。
- 🦀 おおきなカニ：じゃんけん。出す前に、カニの手が「ちらっ」と見える。3回勝てば成功。
- 🍮 ぷるるんゼリー：かざりつけ。クリームやフルーツを3つ以上のせる。「ちゅうもん」と同じものをのせると はなまる が増える。
- ☁️ くもくもさん：ほしを5つ拾って、「ほしの だい」から空へ飛ばす。輪っかが大きいときに押すと「ぴったり」。
- 🌀 いたずらかぜ：おいかけっこ。4回タッチで成功。
- 🌫️ でかもやもや：みんなで えがおを とどける（5回）。エンディング。
- 島の住人（ぽぷり・ごろた・ふわり・かずうさの さんちゃん と ごちゃん）：話しかけると小さなお願いをされる。その島で ものを集めると笑顔になる。かずうさ は『ゆめかわ かずうさガーデン』のブロックのうさぎで、ブロックが戻ると背が伸びる。
- はなまる🌸は1〜3。ごほうびの画面の「もういちど」や、シールちょうの「🔁 あそぶ」で、何度でも遊びなおせる。

## 寄り道とごほうび

- きらきらのかけら：島と橋に24個。ふれると集まり、シールちょうの「はっけん」に記録される。
- えがおシール（11まい）と おてがみ（6つう）。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下に保存データの消去ボタンが出る。

## 構成

ビルド不要。外部のCDN・画像・音声は使わない（音は Web Audio で合成、絵は three.js の図形の組み合わせ）。

- `data.mjs`：島・橋・もや・木や岩・ともだち・住人・ことば・遊びの数値・シール・おてがみ・かけら
- `core.mjs`：島と橋の上の移動と当たり判定（2Dで計算）、ともだちと住人の状態、6つの遊びの進行、はなまる、もや、あんないの道、保存データの整形・検証
- `view.mjs`：three.js による3D表示（three.js は `../punyu-kirakira/vendor/` を流用）
- `audio.mjs`：効果音とBGM（Web Audio で合成）
- `hands.mjs`：じゃんけんの手と、ゼリーのかざりの絵（図形で描く）
- `app.mjs`：画面の切りかえ、会話、スティックとキー入力、保存（localStorage `punyu-hachamecha-v2`）
- `core.test.mjs`：`node --test games/punyu-hachamecha/core.test.mjs`
