# ぷにゅと はちゃめちゃ おたすけ大冒険

小学1年生向けの「おたすけ探索」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

3Dの島（のはら）をぷにゅが自由に歩き回り、困っている友だちに話しかけるとミッションが始まる。成功するとその子が笑顔になり、えがおシールとおてがみがもらえる。全員（5人）を笑顔にすると花火のエンディング。困っている子は段階的に現れる（最初は2人）ので、通しで約1時間遊べる分量をねらっている。会話は文章にせず、頭の上の「！」と絵のふきだしで伝える。失敗・時間制限・ゲームオーバーはない。

## 操作

- タッチ：左下の十字キーで移動、右下の大きなボタンで「話しかける／アクション」。キャラクターや光るものは直接タップでも反応する。
- キーボード：矢印キー / WASD で移動、スペースでボタン。

## ミッション（5人分）

- 🦀 おおきなカニ：じゃんけん。大きなボタンの手（✊✌️✋）で勝負。回を重ねるごとにカニが少し大きくなる。ぷにゅが2回勝ったら成功。負け・あいこは減点なし。
- 🦦 ちゃぷ：光るかいがら探し。島に隠れた光るかいがら3つを探してタップ。
- 🌀 いたずらかぜ：飛ばされた帽子を追う。帽子が島の中をふわふわ移動する。近づいて触れる（5回）と成功。
- 🍮 ぷるるんゼリー：クリームのせ。頭をトントン（タップ5回）するごとにクリームが盛り上がる。
- 💤 くもくもさん：落ちた星集め。星5つを歩いて集める。途中の1つは1回だけ逃げる。

段階開放：最初は カニ と ちゃぷ。両方助けると いたずらかぜ と ぷるるんゼリー、次に くもくもさん が困りごとを持つ。まだ出番でない子は島で眠っている。

## 寄り道とごほうび

- きらきらのかけら：島に10個散らばっている。歩いて触れると集まり、シールちょうの「はっけん」に記録される。
- えがおシール：友だちを助けるごとに1枚。全員笑顔で特別な「にじシール」。
- おてがみ：助けた友だちから、絵中心・一言だけの手紙が届く。タイトル画面とHUDから見られる。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下に保存データの消去ボタンが出る（通常の画面には出ない）。

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない（音は Web Audio で合成、絵は three.js の図形の組み合わせ）。

- `data.mjs`：友だち・ミッション・シール・おてがみ・かけら・島のデータ
- `core.mjs`：移動と当たり判定（2Dで計算）、友だちの状態、段階開放、5ミッションの進行、収集、笑顔、保存データの整形・検証（画面と切り離した計算）
- `view.mjs`：three.js による3D表示（島・ぷにゅ・友だち・帽子・星・貝・かけらは図形の組み合わせで作成。three.js は `../punyu-kirakira/vendor/` を相対インポートして流用）
- `audio.mjs`：効果音とBGM（Web Audio で合成）
- `app.mjs`：画面の切りかえ、タッチ・キー入力、保存（localStorage `punyu-hachamecha-v1`：進みぐあい・シール・おてがみ・かけら・笑顔数・音の設定）
- `core.test.mjs`：`node --test games/punyu-hachamecha/core.test.mjs`。段階開放の順序、全5ミッションをプログラム操作で最後まで進められること、かけら収集、保存データの読み直し、表示テキストに漢字が混ざっていないことを確認
