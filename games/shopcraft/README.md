# SHOPCRAFT（ショップクラフト）

マインクラフト風のブロックの世界で自分の店を建てると、**町のお客さんが本当に買いに来る**ゲーム。
「マイクラで立派な店を作っても、買いに来るお客さんがいない」という小学3年生の願いから企画した。iPad の横持ち（Safari）向け。

ゲーム一覧（トップの `index.html`）から公開中（2026年10月3日公開）。

## 店の作りかた

1. **レジ**を置くと店になる（レジのまわり8マスが1つの店）。
2. その中に**たな**を置いて、タップして品物を並べる（8マスより外のたなは売れない）。
3. お客さんが歩いて入れるようにする（かべで囲むなら**ドア**）。

かんばん（店の名前）・ランプ・かざり・屋根があると★が増える。レジ・たな・かんばんを手に持っているあいだと、置いた直後は、店の範囲が地面に光る輪で表示され、「店が できた！」「レジから 遠いよ」などのお知らせが出る。「あそびかた」にも同じ説明がある。

## 遊びの中心

- **クリエイティブモード**：ブロックは無限。木の板・レンガ・ガラス・色ブロック・屋根・かいだん・さくなどで自由に建てる。
- **店のブロック**：たな（品物を8こ並べる）、レジ（お会計の場所。レジのまわり8マスが1つの店）、かんばん（店の名前を書く）、ドア、ランタン。
- **お客さん**：町の家から歩いて来て、ほしい物をさがし、たなから取ってレジでお金を払い、ひとこと言って帰る。ドアを通るとベルが鳴る。
  - むらびと・ぼうけんしゃ・子ども（最初から）、きし（町レベル2）、まほうつかい（レベル3）、王様の使い（レベル4）。好きな品物が違う。
  - ほしい物がないと「ない みたい…」と言って帰る。その品物は「仕入れ」と「店のひょうか」画面に出る。
  - 店に入れない（ドアがない など）と「入れない…」と言う。
- **店のひょうか（★1〜5）**：品ぞろえ・明るさ・かざり・屋根・広さ・かんばん の6項目。★が多い店ほどお客さんがたくさん来て、チップもくれる。お客さんも「ちょっと くらいね」「かざりが すてき！」のように感想を言う。
- **仕入れ**：売上のコインで、新しい品物（石のけん、ケーキ、鉄のよろい、まほうの本、ダイヤのけん など全22種）を売れるようにする。
- **町のレベル**：売上の合計で町が大きくなり（レベル1〜6）、新しい家が建ち、新しいお客さんが来る。
- **じょうれんさん**：名前のあるお客さん10人。5回買い物をすると、店に飾れる特別なブロック（金ブロック、トロフィー、王様のいす など）をプレゼントしてくれる。「お客さん ちょう」で確認できる。
- **やること**：画面上の目標（最初の売上 → たなに並べる → 仕入れ → 自分の店 → かんばん → ★3 → …）でやることが分かる。

ゲームオーバーはない。最初から小さな屋台があり、すぐにお客さんが来る。

## そうさ（iPad）

| そうさ | すること |
| --- | --- |
| 左下をドラッグ | 歩く |
| 右がわをドラッグ | 見回す |
| タップ | ブロックを置く（たな・レジ・かんばんはタップで画面を開く）。お客さんをタップすると話す |
| 長おし | ブロックをこわす（おしたままで続けてこわす） |
| ▲ | ジャンプ（2回すばやくで「とぶ」） |
| とぶ / ▼ | 空を飛ぶ / 下へ |

パソコンでは WASD・矢印で移動、スペースでジャンプ、Shift で下へ、F で飛ぶ、E でもちもの、1〜9 でブロック選択。マウスはタッチと同じ（ドラッグで見回す、クリックで置く、長おしでこわす、右クリックで置く）。

## 文字

画面の字は、小学3年生までに習う漢字・ひらがな・カタカナだけ。文は短く、ことばの間はスペースで区切る。`text.test.mjs` で、文字列リテラルと HTML に使った漢字が3年生までの配当漢字だけかを調べている。

## 構成

ビルド不要。外部の CDN・画像・音声は使わない（Three.js は MIT ライセンスで `vendor/` に同梱）。テクスチャとアイコンはコードでドット絵として描き、音は Web Audio で合成する。

- `blocks.mjs` — ブロック・品物・お客さん・ひょうか・目標・セリフのデータ
- `world.mjs` — ボクセルの世界（地形、町の家、屋台）、A* の道さがし、レイキャスト、セーブ（ランレングス＋base64）
- `game.mjs` — 店のひょうか、お客さんの行動、売上・仕入れ・町のレベル・じょうれんさん・目標
- `mesher.mjs` — チャンク（16×16）のポリゴン生成（面の省略、AO、箱でできたブロック）
- `textures.mjs`, `icons.mjs` — 16×16 のテクスチャと品物のドット絵
- `render.mjs` — Three.js での表示（チャンク、お客さんのモデル、ドア、かんばんの字、手に持ったブロック、エフェクト）
- `audio.mjs` — 効果音と静かな BGM
- `app.mjs` — タッチ操作、プレイヤーの移動と当たり判定、HUD、パネル、保存
- `*.test.mjs` — ロジック・メッシュ・文字のテスト

セーブは localStorage の `shopcraft-v1`（15秒ごと、画面を閉じるとき、タイトルへ戻るとき）。

```sh
cd games/shopcraft
node --test
```
