# STARFALL WALTZ II — 月蝕の夜想曲

[STARFALL WALTZ](../starfall-waltz/) の続編。ボスとの弾幕決闘が主役の縦スクロール弾幕シューティング。PC（キーボード）、iPad / iPhone（タッチ）対応。縦・横画面対応。

前作の骨格（見た目より遥かに小さい当たり判定、かすり、喰らいボム、スペルアリア、4段階の難易度、スペル練習）はそのままに、ステージ・ボス・弾幕・楽曲・絵をすべて新しく作り、遊びにも三つの要素を足した。

## 遊びの中心

- 当たり判定は自機中央の白い点（半径2.2px）だけ。弾の判定も見た目より小さい。
- かすり（GRAZE）：弾が判定の周囲18pxを通るとスコア。得点アイテムの価値と**共鳴ゲージ**が上がる。
- **共鳴（RESONANCE）とフォルティッシモ**：ゲージはかすり・スペル取得・上部回収で溜まり、満タンで自動的にフォルティッシモが始まる（約9秒）。ショットの威力1.35倍、アイテムは画面のどこにいても最大価値で回収、得点アイテムの価値1.5倍、かすりの得点2倍。始まりの一拍ですぐそばの弾が星に変わり、最中に被弾しても共鳴が一度だけ身代わりになる（ミスにはならないが、スペルのボーナスは失う）。攻めて避けるほど守りも厚くなる。
- 喰らいボム：被弾してから10フレーム（約1/6秒）はまだ間に合う。自機の周りで縮む赤い輪が猶予の残り時間。
- ボムは自機ごとに違う。
  - ノヴァ「スーパーノヴァ」：画面の弾を星アイテムに変えて消し、約3.7秒無敵。
  - クレメンタイン「グランド・ポーズ」：約2.8秒、時が止まる。敵・弾・攻撃の残り時間は動かず、自機のショットだけが届く。止まった弾には当たらず、最後にすべて星になる。
- ショットも違う。ノヴァは追尾する星（低速で集中の針）。クレメンタインは広がる歯車（低速で、雑魚を貫通する長針）。移動は少し遅い。
- スペルアリア：宣言時に立ち絵のカットインと専用背景。被弾・ボムなしで倒すと残り時間に応じたボーナス。時間切れまで耐える耐久アリアもある。挑戦・取得の履歴を難易度別に保存。
- 道中は約40秒＋中ボス。ボス前に会話（自機によって台詞が変わる）。
- 難易度：LARGO / ANDANTE / ALLEGRO / PRESTO。LARGO は ANDANTE と同じ形の弾幕を弾速0.75倍・弾数約6割・ボス体力0.65倍にしたもの（残機4・ボム4・喰らいボムの猶予約0.4秒・コンティニュー無制限）。
- アリア・プラクティス：本編で出会ったスペルアリアを単独で練習できる。
- 音楽室：全12曲を、作ったときのメモつきで聴ける。スペクトラム表示つき。
- 処理が重いときは時間を捨ててスローになる（弾がワープしない）。設定の「画面の演出」を「かるい」にすると、背景の景色と光のにじみを省く。

## 物語とステージ

大天球儀が調律を取り戻してから、しばらく。こんどは月が欠けたまま戻らず、夜から「音」が消えていく。

1. **AURORA PROMENADE 極光の遊歩道** — ルミ・ボレアリス（極光の機織り）。抜けていく音を光の幕にしまい込んでいる。高さによって波打つ幕が交互に降りる「オーロラ・カーテン」、うねりながら進む「ボレアリス・リボン」。
2. **TIDEGLASS OBSERVATORY 潮硝子の天文台** — マリス・ノクティルカ（潮汐の観測手）。止まった海を腕で引いている。弾けて雫の輪になる「シーフォーム」、放物線の噴水が潮の向きで流される「スプリング・タイド」、外から中心へ巻き込む「ノクティルカの渦」。
3. **COMET ARCHIVE 彗星書庫** — ハレー・クイル（彗星の司書）。棚の通路をなぞって折れる「コール・ナンバー」、ボスを焦点にした楕円を近いほど速く回り、尾が反対へ伸びる「ハレーズ・テイル」、左右から滑る本棚の列「バベルの図書館」、遠ざかって戻ってくる「七十六年目の帰還」。
4. **UMBRA THRONE 蝕の玉座** — 中ボスはセレネ（前作の「ケプラーの楕円」を二つの焦点で再演）。ボスはノクス・エクリプティカ（月蝕の歌姫）。音符が止まり向きを変える「フェルマータ」、予告線ごと回る光の一閃「ダイヤモンドリング」、灯りの届く範囲だけがはっきり見える「月のない夜のノクターン」、耐久「コロナ」、終曲「星降る円舞曲・第二夜」（三拍子の星と流星 → 渦を巻く銀河 → 夜明けの金色の音符）。

世界観・キャラクター・弾幕・音楽はすべてオリジナル。東方Projectの「ボス戦中心・美しい弾幕・小さな当たり判定・喰らいボム」という遊びの骨格を参考にしている。

## 音楽

全12曲をその場で合成する（外部の音源ファイルなし）。

- 曲は `songs.mjs` に、パートごとの MML（`o5 l8 c4 g4 a- g f e- |` のような記法）とコード進行で書く。主旋律・対旋律は手書き、ベース・鍵盤・パッド・太鼓はコード進行と「型」から組み立てる。主旋律には、その時のコードの音で自動的に下のハモりをつけられる。
- 楽器は15種：トランペット、ヴァイオリン、フルート、ピアノ、ハープ、チェンバロ、オルゴール、ベル（FM合成）、マリンバ、オルガン、弦のパッド、合唱（フォルマント）、ベース、ピチカート。太鼓9種は起動時に波形を計算して作る。
- パートごとに音量・左右の定位・残響とディレイへの送りを持つ。残響は高音ほど早く消えるインパルス応答、ディレイは曲のテンポに合わせて左右に跳ね返る。
- 曲の拍は描画にも渡り、魔法陣・背景・フォルティッシモの縁取りが拍に合わせて脈打つ。
- 主題のつながり：タイトル曲は前作の主題をオルゴールで8小節鳴らしてから新しい主題へ移る。セレネの曲は前作の最終ボス曲を一音も変えずに編み直したもの。最終スペルの曲はタイトル曲の主題が短調からニ長調に変わり、エンディングはその長調版をオルゴールが弾く。

## 構成と実行

ビルド不要。HTTPでこのフォルダを配信する。実行時に外部のCDN・画像・音声・フォントを取得しない。

- `consts.mjs`: 画面サイズ、当たり判定、難易度、自機、弾の種類などの定数
- `core.mjs`: 1フレーム単位のシミュレーション（自機、弾、かすり、被弾と喰らいボム、二種のボム、共鳴、アイテム、スペル取得、中ボス、進行）。DOM非依存
- `content.mjs`: 道中の敵、ボス、会話、全23攻撃
- `music.mjs`: MMLの解釈と、曲データから発音の一覧を作る処理（音は鳴らさない）
- `songs.mjs`: 全12曲の譜面と解説
- `audio.mjs`: 楽器・太鼓・残響の合成、再生、効果音
- `gl.mjs`: 背景のシェーダー（4面＋スペル用の模様）
- `art.mjs`: キャラクターの絵
- `render.mjs`: Canvas描画（弾のアトラス、敵、演出、画面内表示、光のにじみ）
- `app.mjs`: 画面遷移、入力、60fps固定刻み、保存（localStorage `starfall-waltz-2-v1`。前作とは別）
- `core.test.mjs`: 判定・進行・楽曲データの検証

```sh
node --test games/starfall-waltz-2/core.test.mjs
python3 -m http.server 8000
```

## 検証範囲

自動テストで、小さな当たり判定とかすり、高速弾のすり抜け防止、喰らいボムの猶予、二種のボム（時間停止中は弾も残り時間も進まず、止まった弾に当たらず、最後に星になる）、自機ごとのショットと貫通、共鳴ゲージとフォルティッシモの身代わり、スペル取得・耐久・時間切れ、上部回収、残機増加、レーザーの予告、ゲームオーバーとコンティニュー、全23攻撃×4難易度×両自機の完走と弾数、同一シードの再現性、両自機での本編4ステージ通し進行（中ボス・会話・曲の切り替えを含む）、最終スペルの楽章、LARGOの弾速・弾数・体力を確認。楽曲は、MMLの解釈、全12曲の各パートの長さと小節線、音域、主旋律とコードの濁りを確認。先読みで避ける簡易ボットで各攻撃が回避可能なことも確認した。ヘッドレスChromiumで、全画面の描画とシェーダーのコンパイル、音声処理にエラーがないこと、全12曲をオフライン合成して音割れがないことを確認。

実機での操作感・難しさの手応え・**音の聴こえ方（旋律の良し悪し、楽器の混ざり具合）**・iPadでの処理速度は、自動では確かめられないので試遊で確認する。
