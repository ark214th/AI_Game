# STARFALL WALTZ — 星降る円舞曲

ボスとの弾幕決闘が主役の縦スクロール弾幕シューティング。PC（キーボード）、iPad / iPhone（タッチ）対応。縦・横画面対応。

## 遊びの中心

3人のボスが、名前のついた弾幕「スペルアリア」を次々に繰り出す。見た目より遥かに小さい当たり判定で弾のすき間をすり抜け、すれすれで避けるほど得点が伸びる。

- 当たり判定は自機中央の白い点（半径2.2px）だけ。弾の判定も見た目より小さい。低速移動中は点と照準リングがはっきり表示される。
- かすり（GRAZE）：弾が判定の周囲18pxを通るとスコア、かつ得点アイテムの価値が上がる。1発につき1回。
- 喰らいボム：被弾してから10フレーム（約1/6秒）はまだ間に合う。自機の周りで縮む赤い輪が猶予の残り時間。ボムを押せば被弾は取り消し。
- スーパーノヴァ（ボム）：画面の弾を星アイテムに変えて消し、約3.7秒無敵。ミスするとボムは3発に戻る。
- スペルアリア：宣言時にカットインと専用背景。被弾・ボムなしで倒すと残り時間に応じたボーナス。時間切れまで耐える「耐久アリア」もある。挑戦・取得の履歴を難易度別に保存。
- 通常攻撃とスペルアリアが交互に来るボス戦。ボスの残りスペル数、体力、残り時間（最後の10秒はカウントダウン音）を表示。
- 道中は短め（約35〜40秒）でパワーと得点を集め、ボス前に会話。ボス戦はステージの大半を占める。
- アイテム：P（パワー、最大4.00でオプション4つ）、✦（得点。一定数で残機+1）、弾消しの星。画面上部の線より上で全回収（最大価値）。
- 低速移動でショットが前方集中の針に、通常移動では敵を追う星になる。
- 難易度：LARGO / ANDANTE / ALLEGRO / PRESTO。コンティニュー3回（スコアは回数にリセット）。
- LARGO（はじめて）：ANDANTEと同じ形の弾幕を、弾速0.75倍・輪や扇の弾数約6割にしたもの。ボスの体力0.65倍、残機4・ボム4発、喰らいボムの猶予24フレーム（約0.4秒）、コンティニュー無制限。
- アリア・プラクティス：本編で出会ったスペルアリアを単独で練習できる。
- 処理が重いときは時間を捨ててスローになる（弾がワープしない）。

### 操作

| | キーボード | タッチ |
|---|---|---|
| 移動 | 矢印 / WASD | 画面のどこでもドラッグ（相対移動、感度は設定で調整） |
| 低速 | Shift（押している間） | FOCUSボタン（切り替え。移動量も0.55倍） |
| ボム | X / K | 2本目の指でタップ（移動中でも可、2本同時タップでも可）/ NOVAボタン |
| ショット | 自動 | 自動 |
| 会話 | Z / Enter（Ctrlでスキップ） | タップ / SKIP |
| 一時停止 | Esc / P | Ⅱボタン |

メニューは矢印キーとZ / Enter、X / Escで戻る。左右キーで難易度変更。

## 世界観と表現

東方Projectの「ボス戦中心・美しい弾幕・小さな当たり判定・喰らいボム」という遊びの骨格を参考にし、和風ではなく西洋の天文学・時計仕掛け・ステンドグラスをモチーフに独自制作。キャラクター、弾幕、音楽はすべてオリジナル。

1. **BRASS GARDEN 真鍮の歯車庭園** — クレメンタイン（時計仕掛けの踊り子）。歯車の歯が飛び散る「トゥールビヨン」、1秒ごとに弾が止まり向きを変える「真夜中の鐘」。
2. **ROSE WINDOW NAVE 薔薇窓の聖堂** — アイリス・ヴィトレイユ（薔薇窓の精）。薔薇曲線で広がる「ローズウィンドウ」、白い光球が七色に分かれる「七色の分散」、回転するレーザー。
3. **THE GRAND ORRERY 大天球儀** — セレネ・アストライア（大天球儀の主）。重力で楕円軌道を描いてから放たれる「ケプラーの楕円」、3拍子に合わせた「流星のワルツ」、耐久「ハルモニア・ムンディ」、最終「星降る円舞曲」。

音楽は全曲3/4拍子のワルツ（オルゴール、道中、ボス曲）。Web Audioで合成し、残響もその場で生成。弾は白い芯と色の縁で背景から読み取りやすくし、背景は弾より暗く保つ。

## 構成と実行

ビルド不要。HTTPでこのフォルダを配信する。実行時に外部のCDN・画像・音声・フォントを取得しない。

- `consts.mjs`: 画面サイズ、当たり判定、喰らいボム猶予などの定数
- `core.mjs`: 1フレーム単位のシミュレーション（自機、弾、かすり、被弾と喰らいボム、ボム、アイテム、スペル取得、進行）。DOM非依存
- `content.mjs`: 道中の敵、3人のボス、会話、全14攻撃（スペルアリア8種）
- `render.mjs`: Canvas描画（弾の画像をまとめたアトラス、背景、ボス、カットイン、画面内表示）
- `audio.mjs` / `music.mjs`: 効果音と楽曲データ・合成
- `app.mjs`: 画面遷移、キーボード・タッチ入力、60fps固定刻み、保存（localStorage `starfall-waltz-v1`）
- `core.test.mjs`: 判定と進行の検証

```sh
node --test games/starfall-waltz/core.test.mjs
python3 -m http.server 8000
```

## 検証範囲

自動テストで、小さな当たり判定とかすり、高速弾のすり抜け防止、喰らいボムの猶予（10フレーム目まで間に合い、11フレーム目は間に合わない）、被弾中の移動不可、ボムの弾消しとスペル失敗、スペル取得・耐久・時間切れ、上部回収、残機増加、レーザーの予告、ゲームオーバーとコンティニュー、全14攻撃×4難易度の完走と弾数、LARGOの弾速・弾数・体力・猶予、会話中のボム無効、同一シードの再現性、本編3ステージの通し進行、楽曲データを確認。先読みで避ける簡易ボットで全攻撃が回避可能なことも確認した。ヘッドレスChromiumで描画・音声処理のエラーがないこと、実際のタッチイベントでの2本指ボム、旧形式の保存データの引き継ぎ、スマートフォン縦画面とタブレット横画面の配置を確認。実機での操作感・難しさの手応え・音の聴こえ方は試遊で確認する。
