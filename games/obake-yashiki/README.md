# オバケやしきの おかたづけ（開発中）

小学3年生向けの、本を片付けるゲーム。『Librarian: Tidy Up the Arcane Library!』の「散らかった図書館が、だんだん片付いていく気持ちよさ」と「魔法が増えて、片付けがはかどっていく成長」を、iPad で遊べる形にしたもの。

## 遊び方

- 目の高さの 3D の図書室を歩く。SHOPCRAFT と同じく、画面の左下を触るとその場に出るスティックで歩き、それ以外の場所をなぞると見回せる（両手で同時にできる）。本棚・テーブル・本の山にぶつかると、そのふちに沿ってすべる。
- 本をタッチすると拾う（はじめは4冊まで）。遠くの本や棚をタッチすると、山やテーブルをよけてそこまで自動で歩く。
- 本の表紙と背には「たなのマーク」と「シリーズの名前」と「巻数」が書いてある。マークで本棚（うちゅう・うみ・どうぶつ・まほう）を探し、名前で段を探して、段をタッチするとしまえる。本の色は手がかりにならない。
- 違う棚では「ここじゃ ないみたい」、同じ棚の別の段なら「おしい！」と教える。失敗しても何も起きない。
- 1段（8冊）そろうと、なかまのオバケ「ふわり」が魔法を教えてくれる。

| そろった段 | 覚えること |
|---|---|
| 1 | よびよせ：近くの本が手もとに飛んでくる |
| 3 | おおきな かばん：6冊持てる |
| 6 | みちしるべ：持っている本の棚と段が光る |
| 9 | とんでけ：持っている本が自分で棚へ飛んでいく |
| 12 | まほうの かばん：8冊持てる |
| 15 | つむじかぜ：床の本が10冊いっきに棚へ |

- 全192冊（4つの棚 × 6段 × 8巻）を戻すとクリア。進み具合は自動で保存され、「つづきから」で再開できる。

## 見た目

- 画像は使わず、本の背表紙・表紙・木目・じゅうたん・窓の夕焼けまで、すべて canvas で描いている。
- 本棚を埋める飾りの本（約3800冊）は1つの InstancedMesh でまとめて描く。片付ける本は1冊ずつ別のメッシュ（描画は2回）。
- 3D は `vendor/` の three.js（r180、他のゲームと同じもの）を使う。

## ファイル

- `core.mjs` — ルール（本と棚の配置、拾う・しまう、魔法の解放、保存、歩く道さがし）
- `view.mjs` — 3D の描画（部屋、本棚、本、光、きらきら）
- `app.mjs` — タッチ操作、歩く・見回す、魔法、画面の文字
- `audio.mjs` — 効果音（Web Audio）
- `core.test.mjs` / `text.test.mjs` — `node --test` で実行
