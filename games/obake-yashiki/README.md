# オバケやしきの おかたづけ（開発中）

小学3年生向けの、本を片付けるゲーム。『Librarian: Tidy Up the Arcane Library!』のような「散らかったモノを正しい棚に戻す」遊びを、いたずらオバケとの駆け引きにアレンジしたもの。iPad 横持ち向け、斜め見下ろしの1画面。

## 遊び方

- 床の本をタッチすると、かごに入る（5冊まで）。
- 同じ色・同じマークの棚をタッチすると、かごの中の本が番号の場所に戻る。かごの本と合う棚はうっすら光る。
- ときどきいたずらオバケが来て、本の多い棚をねらう。指で押さえ続けてライトのゲージを満タンにすると追い払える（その間は片付けが止まる）。
- オバケが棚に届くと、その棚の本とかごの中身が床に散らかる。たくさん抱えるほど、やられたときの損が大きい。
- 全20冊を戻すとクリア。ゲームオーバーはなし。

## ファイル

- `core.mjs` — ルール（本の配置、かご、棚への収納、オバケに散らかされる処理）
- `app.mjs` — 描画・入力・オバケの動き
- `audio.mjs` — 効果音（Web Audio）
- `core.test.mjs` / `text.test.mjs` — `node --test` で実行
