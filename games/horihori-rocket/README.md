# ほりほり ロケット工場

小学3年生向けの、ほって・はこんで・売って・強くする ゲーム。「地面を掘って資材を集め、ベルトコンベアで運んでホッパーに入れるとお金がもらえ、新しい機材を買って効率を上げる」という息子さんのアイデアから企画した。A Game About Digging A Hole の「掘る→売る→強くする」と、マイクラの自動化（ベルトコンベア・ホッパー）をあわせた形。iPad・iPhone の横持ち（Safari）向け。

ゲーム一覧（トップの `index.html`）から公開中（2026年10月25日公開）。

## 遊び方

1. ◀ ▶ で動く。かべに向かって押すと横に掘れる。▼ で下を掘る。▲ でジェットで飛ぶ（天井に当たると上も掘れる）。
2. 掘った鉱石はバッグに入る。地上の **ホッパー**（緑のじょうご）に近づくと自動で売れる。
3. 🛒おみせで道具（ドリル・バッグ・でんち・ジェット）を強くする。深い層ほど硬く、強いドリルがいる。
4. 🔧つくる で **ベルト** を掘った所に並べてホッパーとつなぐ（流れる向きは自動）。ベルトの上に立つとバッグの鉱石を乗せられる。
5. 基地に **作業場** を建てると **じどうドリル** が置ける。ベルトでつなぐと、ずっと鉱石をホッパーへ運んでくれる。
6. ゴールは **ロケット**。5つのパーツそれぞれに、地下の「たから」とお金がいる。そろったら発射してクリア（そのあとも遊べる）。

- 層：土 → 石 → かたい石 → くらい石 → あつい石 → すいしょう → ちきゅうの まんなか（深さ 0〜240m）。鉱石は 炭・鉄・銀・金・ルビー・ダイヤ・にじいろの石。
- 基地（見た目も変わる）：作業場・化石の へや・見はり台（たからの方向を矢印で表示）・ロケットきち・工場（売値1.5倍）・テレポーター（🏠ですぐ地上へ）。
- 化石は8種類。見つけるとボーナス。化石の へやで見られる（⚙️ せってい から）。
- ゲームオーバーなし。でんちが切れても地上に戻されるだけで、鉱石もお金も減らない。機材を取り消すと払ったお金は全部戻る。
- 画面の漢字は小学3年生までに習うものだけ（`text.test.mjs` で確認）。

## ファイル

- `index.html` / `style.css` — 画面とボタン
- `app.mjs` — 操作・物理・カメラ・描画のまとめ・お店や画面の切りかえ
- `core.mjs` — きまり（世界の生成、掘る、売値、ベルトの流れ、じどうドリル、やること、保存）
- `draw.mjs` — 絵（すべて図形でかく）
- `audio.mjs` — 効果音と BGM（Web Audio）
- `core.test.mjs` / `text.test.mjs` — `node --test` で動くテスト

保存：ブラウザの localStorage（`horihori-rocket-v1`）。キーボードでも遊べる（矢印キー / WASD）。
