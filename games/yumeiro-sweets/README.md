# ゆめいろ おかしやさん

小学1年生向けの、おかし作りゲーム。まほうの パティシエに へんしんして、お客さんの ちゅうもんに あわせて ケーキや ドーナツを かざる。

## 遊び方

1. はじめて あそぶときに、ひらがな（カタカナ）の キーボードで なまえを いれる（「あとで きめる」も できる。せっていから かえられる）。
2. へんしん シーンの あと、おみせに お客さんが きて ちゅうもんする。
3. 「つくる！」で キッチンへ。えらぶ → ぬる → しぼる → のせる → まほう の 5つの じゅんばん。
4. できた おかしを わたすと、お客さんが よろこんで ハートを くれる。ちゅうもんどおりだと だいよろこび（ちがっても ハートは もらえる）。
5. ハートが たまると、おかし・クリーム・トッピング・お客さん・ドレス・おみせの かべが ふえる。

- つくった おかしは アルバムと おみせの たなに のこる。
- ゲームオーバーなし。時間制限なし。

## ファイル

- `index.html` / `style.css` — がめんと ボタン
- `app.mjs` — ばめんの すすみかた・そうさ
- `core.mjs` — きまり（かざれる ばしょ、ちゅうもん、ハート、なまえ入力、ほぞん）
- `data.mjs` — おかし・お客さん・ふえる もの の データ
- `draw.mjs` — え（すべて ずけいで かく）
- `audio.mjs` — こうかおんと BGM（Web Audio）
- `core.test.mjs` — `node --test` で うごく テスト

ほぞん：ブラウザの localStorage（`yumeiro-sweets-v1`）。
