# ポムの きらきらランド（仮）企画・事前設計案

作成日：2026年9月27日
状態：内容はおおむね確定（2026年9月27日）。主人公の名前のみ未定。実装は未着手。
テストプレイ：保護者（大人）が行う。お子さんには完成版を初めて見せる。
想定プレイヤー：小学1年生（6〜7歳）。ひらがなが読める。ゲームの経験は少なめ。
想定環境：iPhone・iPad の横持ち、Safari（ホーム画面に追加して全画面で遊ぶ使い方も含む）。PCのキー操作にも対応する。

## 1. 目指す体験

**まるくてかわいい主人公が、ぴょんと跳ねて、ばねで飛び、坂をびゅーんと駆け抜ける。失敗しても怖くない。遊ぶたびに集めたものが増えていく。**

優先順位：

1. **操作が2種類だけで遊べる**：動く、跳ぶ。それ以外のボタンは要らない。
2. **失敗が怖くない**：ゲームオーバーなし。落ちてもすぐ近くから再開できる。
3. **かわいい見た目と気持ちいい手ごたえ**：ぷにっと弾む主人公、きらきらした音と光。
4. **スピード感**：ソニックのような速さは、プレイヤーの腕ではなく「地形」が生む（ばね、坂、ダッシュパネル、ループ）。

### 既存作品「ミミの にじいろ大冒険」との違い

リポジトリには同じ小学1年生向けの横スクロール作品（`rainbow-bunny`、2Dの平面の絵）がすでにある。新作は次の点で差をつける。

| | ミミの にじいろ大冒険 | 新作（本案） |
| --- | --- | --- |
| 見た目 | 2D（平面の絵） | 3Dで描くキャラと背景（擬似3D、横からのカメラ） |
| スピード | ふつうの歩き・ジャンプ | ばね・坂・ループによる加速の演出 |
| 繰り返し遊ぶ理由 | ステージクリア | きせかえ・シール集めで遊ぶたびにごほうびが増える |
| 対応端末 | iPad 中心 | iPhone でも遊べる大きさの操作ボタン |

## 2. 主人公と世界観

### 主人公（案）

- **ポム**：手のひらサイズのまるい子。ハムスターとお餅の中間のような、ころんとした見た目。耳と短いしっぽ、ほっぺは赤い。
- 3Dの丸い形（球・カプセル）を組み合わせて作るので、画像素材がなくても見た目を作れる。走ると体がつぶれたり伸びたりして弾む。
- セリフは短いひらがなだけ。「やったー！」「ぴょーん！」など。

主人公の候補はほかに、こねこ、ひよこ、ペンギン、うさぎも考えられる（うさぎは既存作品とかぶる）。**名前は「ポム」より、もっとかわいい響きのものに変更予定（候補は10章）。**

### お話

> きらきらランドの「ほしのかけら」が、いたずら好きのかぜで ぜんぶ とんでいっちゃった。
> ポムは ともだちと いっしょに、かけらを あつめに でかけるよ！

- 悪者は出さない。敵はいたずらっ子のキャラで、倒すのではなく「ぽよんと踏むと目を回して逃げていく」。
- 各ワールドの最後に大きなほしのかけらがあり、取ると空に星が1つ戻る。タイトル画面の夜空に星が増えていく。

### ワールド構成（完成版の目安）

| ワールド | 見た目 | 新しく出てくる仕掛け |
| --- | --- | --- |
| 1. おはなの のはら | 花畑、ちょうちょ、青空 | ジャンプ、ばね、ゆるい坂 |
| 2. おかしの もり | ケーキの足場、キャンディの木 | 動く足場、ダッシュパネル |
| 3. ふわふわ くものうえ | 雲の足場、にじの橋 | ふわっと浮く雲、小さなループ |
| 4. きらきら うみべ | 砂浜、しゃぼん玉、貝殻 | しゃぼん玉に乗って浮く |
| 5. ほしぞらの おしろ | 夜空、ランタン、星の道 | これまでの仕掛けのまとめ |

各ワールド3ステージ。**ボス戦は入れない。** ワールドの3ステージ目は、そのワールドの仕掛けをまとめて楽しむ少し長めのステージにし、最後に大きなほしのかけらと、星が空に戻るお祝いの演出を置く。

**最初に作る範囲は、ワールド1の3ステージだけ**。まず遊べる形にして、保護者のテストプレイで調整してから追加する。

## 3. 操作

### 基本案：3つの大きなボタン

```
┌──────────────────────────────────────────┐
│ ★12   ●●○                     ⏸       │
│                                          │
│              （ゲーム画面）              │
│                                          │
│  ┌───┐ ┌───┐                  ┌─────┐   │
│  │ ◀ │ │ ▶ │                  │ぴょん│   │
│  └───┘ └───┘                  └─────┘   │
└──────────────────────────────────────────┘
```

| 入力 | 役割 |
| --- | --- |
| ◀ ▶（左手） | 押している間、その方向へ走る。押し続けると少しずつ速くなる |
| ぴょん（右手） | ジャンプ。長く押すと少し高く跳ぶ（短く押しても十分な高さが出る） |

- ボタンは大きく、iPhoneでも親指で押し間違えない大きさにする。画面の端（ノッチ・ホームバー付近）からは離す。
- ボタンの外側を触っても反応する「広めの当たり判定」にする。子どもは狙った場所から少しずれて押しがちなため。
- 二段ジャンプ、ダッシュボタン、しゃがみ、攻撃ボタンは入れない。
- 敵は上から踏めば倒れる。ばね・ダッシュパネル・ループは触れるだけで自動で働く。

### 補助オプション：「おまかせ はしり」

設定でオンにすると、ポムが自動で右へ歩き、プレイヤーは「ぴょん」だけを押せばよい（ボタン1つ）。左右の操作がまだ難しい場合や、もっと小さい子が遊ぶ場合向け。初期設定はオフ。

### PC

左右キー（またはA/D）で移動、スペース・上キーでジャンプ。

## 4. やさしさの仕組み（難易度を上げすぎない）

### 失敗しても怖くない

- **ゲームオーバーなし・残機なし・制限時間なし**。
- ハートは3つ。敵やトゲに当たると1つ減り、少しの間点滅して無敵になる。ハートがなくなったら、直前の「チェックポイントの旗」から再開（集めた星はなくならない）。
- **穴に落ちてもしゃぼん玉で助かる**：穴に落ちると、しゃぼん玉に包まれてふわっと直前の足場へ戻る。ハートが1つ減るだけ。
- チェックポイントは約20〜30秒ごと。

### 操作のずれを許す

- 足場の端から少しはみ出しても、ほんの一瞬はジャンプできる。
- 着地の少し前に押したジャンプも、着地した瞬間に出る。
- 敵の当たり判定は見た目より小さく、踏む判定は見た目より広くする。
- 穴の幅は、ふつうに走って跳べば余裕で越えられる幅だけにする。

### スピードは「見せる」けれど「怖くしない」

- 高速の区間（ばね、ダッシュパネル、ループ）は、その間ほぼ自動で安全に進む作り。高速中に穴や敵を置かない。
- 高速中はカメラが少し先を見せる。見えない所から急に危険が来ないようにする。
- 高速区間の後には、ゆっくり歩ける安全な場所を置く。

### 迷わせない

- 基本は右へ進むだけ。ゴールへの道は1本で、寄り道（高い所・隠し部屋）は任意。
- 文字を読まなくても分かるように、初めての仕掛けは「→」や光るアイコンで示す。
- 文字はひらがなだけ、大きめ、少なめ。

## 5. 集めるもの・繰り返し遊ぶ理由

| もの | 意味 |
| --- | --- |
| ほしつぶ（小さな星） | 道にたくさん並ぶ。取ると「ちりん」と鳴る。100個でハートが1つ戻る |
| にじいろメダル（各ステージ3枚） | 少し隠れた場所や、ばねの先にある。全部取らなくてもクリアできる |
| ほしのかけら | ステージのゴール。取るとクリア |

- ステージの結果は「メダル何枚取れたか」だけを見せる。タイムやスコアの順位は出さない（比べて落ち込ませないため）。
- **ごほうび**：集めたほしつぶとメダルで、ポムの**きせかえ**（リボン、帽子、めがね、色）や**シール帳**のシールが解放される。帽子などはゲーム中の3Dのポムにも反映される。
- 進み具合は端末に自動で保存する。

## 6. 1回の遊び時間

- 1ステージ：約1分半〜3分。
- ワールド1（3ステージ）：10分前後。
- 区切りが短いので「あと1回だけ」で止めやすい。
- 保護者向け設定（任意）：「◯分あそんだら おしらせ」機能。

## 7. 見た目・音

### 擬似3Dの描き方

- 3D描画ライブラリ（three.js。リポジトリ内の他作品でも使用済み）を使う。
- **ゲームの動き（当たり判定・ジャンプ）は左右と上下だけの2Dで計算**し、見た目だけを3Dで描く。操作は横スクロールの分かりやすさのまま、立体感だけを足す。
- カメラは真横よりやや上・やや斜めから見下ろす。奥に木・山・雲を重ね、進むと遠くの物がゆっくり動いて奥行きが出る。
- 主人公やアイテムは丸みのある形に、やわらかい影と輪郭線（トゥーン調）をつける。パステルカラー中心。
- ポムは走るとくるくる転がる／跳ぶとぷにっと伸びる、など体の弾みで気持ちよさを見せる。

### 音

- 明るいBGM（ワールドごとに1曲）と、ジャンプ・星・ばね・メダルの効果音。音はプログラムで合成し、外部の音声ファイルに頼らない。
- iPhoneの消音スイッチがオンでも音量ボタンで調整できる程度にし、音量設定を用意する。

## 8. iPhone・iPad への対応

- 横持ち専用。縦向きのときは「よこにしてね」の案内を出す。
- ノッチ・ダイナミックアイランド・ホームバーを避けてボタンと表示を置く。
- 画面の大きさが違っても、見える範囲（縦方向の高さ）がほぼ同じになるように調整する。iPadは横に少し広く見える。
- ホーム画面に追加すると、アドレスバーなしの全画面で遊べるようにする。
- 誤操作防止：ダブルタップでの拡大、長押しでの文字選択、スワイプでのページ戻りを無効化。
- 古めのiPhoneでもなめらかに動くように、影や描き込みの量を自動で調整する。

## 8.5 大人がテストプレイするときの目安

テストプレイは大人が行うため、「大人がやって少し簡単すぎる」くらいを正解とする。調整の目安：

- 大人が初見で、ほとんどハートを減らさずにクリアできる。
- 片手（右手の親指だけ、「おまかせ はしり」オン）でもクリアできる。
- 大人が「わざと下手に」遊んで（ジャンプを遅らせる・連打する）も、ハートがなくなる場面がほぼない。
- にじいろメダルは、大人が少し探せば全部見つかる。

テスト用に、URLに `?debug` を付けたときだけ使える機能を用意する：ステージを直接選ぶ、無敵、当たり判定の表示、保存データの消去。お子さんが遊ぶ通常の画面には出さない。
