# ヒルホップ・ガレージ（仮）事前設計案

作成日：2026年9月11日  
状態：制作前の提案。ゲームの実装・公開は未着手。  
想定環境：iPad横持ち・Safari。タッチ操作を基準に、PCのキー操作にも対応する想定。

## 1. 目指す体験と優先順位

**下り坂で勢いをつけ、小さなジャンプで荒れ地をかわし、次の斜面へ滑らかに着地する。その気持ちよさを、愛車の強化と新しい土地への旅につなげる。**

1. 強化していない車でも、坂を走る操作そのものが面白い。
2. 腕が上がることと車が強くなることの両方で、前より先へ進める。
3. 統一された絵柄・車の動き・音・画面演出で、小規模な完成作品として見せる。

詳細なデバッグ、コード整理、将来に備えた設計、体験に現れていない性能対策は後回し。入力が反応しない、地面を抜ける、到達不能な配置、進行やセーブが失われる問題は体験を壊すため優先して直す。

以下の秒数、回数、金額は調整開始時の仮値。プレイによる検証済みの値ではない。とくに「何周でクリアできるか」は目標であり、保証値ではない。

## 2. ゲームの基本構造

小さなオフロード車に乗り、各地域のゴールを目指す横スクロールのドライブゲーム。道路は右へ続き、上り下り、細かな起伏、段差が主な障害になる。

- 1回の出走はおおむね1〜3分。上達後の地域完走は2〜3分程度を狙う。
- 初回完成版は3地域。それぞれにスタートとゴールがある。
- 地域を初めて完走すると、次の地域が開く。入場料や強化レベルによる追加の解放条件は設けない。
- 解放済みの地域は、次回から直接選んで出発できる。選択は前回のものを記憶する。
- 地域内には進捗の目印を置くが、途中から再開するチェックポイントではない。
- 失敗しても集めたコインを全額持ち帰る。出走費用はかからない。
- 燃料は出走時に満タン。一時効果は出走ごとにリセット。恒久強化、解放状態、所持金、記録は残る。

### 操作

| 入力 | 地上での役割 | 空中での役割 |
| --- | --- | --- |
| アクセル | 加速、坂を登る | 車の鼻先を少し上げる |
| ブレーキ | 減速。停止後の長押しでゆっくり後退 | 車の鼻先を少し下げる |
| ジャンプ | 押した瞬間に跳ぶ。短押しは低く、少し長く押すと高くなる | 離すと上昇の追加を止める。二段ジャンプはない |
| 何も押さない | 惰性で進む。下りで燃料を節約 | 緩やかな姿勢補助が働く |

左手側にアクセルとブレーキ、右手側にジャンプを置く。アクセルとジャンプを同時に使える配置とし、主要ボタンを画面の端ぎりぎりに寄せない。PCでは左右キーとスペースを対応させる。

空中での姿勢操作は上達の余地として用意する。何も操作しなくても通常の小ジャンプを着地できる程度の補助を入れ、常に細かな姿勢修正を要求しない。

### 終了と復帰

- **燃料切れ**：燃料が0になると駆動とジャンプが使えなくなる。すぐには終了せず、惰性や下りで進める。燃料缶を拾えば復活する。ほぼ停止した状態が約2秒続くと終了。
- **落下**：落とし穴の底に落ち、コースへ戻れない位置に達すると終了。
- **転倒**：即終了にはしない。短い待ち時間の後、同じ場所で起こす。速度を失い、復帰中も通常の待機分の燃料を使う。穴の中からの救出には使えない。
- 車体のHP、衝突による即死、複雑な部位破損は初回完成版に入れない。

## 3. 操作だけで面白くする仕組み

### 3.1 「勢いを次の坂へ渡す」が主役

典型的な20秒間は、次のようになる。

1. 緩い下りに入り、アクセルを離して燃料を節約しながら加速する。
2. 谷底の細かな凹凸を、短いジャンプでまとめてかわす。
3. 次の斜面に車体を合わせて着地し、速度を保ったまま坂を登る。
4. 丘の頂上で、高い位置のコインを狙うか、低く走って先の燃料を確実に拾うかを選ぶ。

速さだけでなく、アクセルを離す場所とジャンプの大きさに意味を持たせる。燃料は単なる制限時間ではなく、走り方によって航続距離が変わる資源にする。

### 3.2 ジャンプには三つの使い道がある

| 使い方 | 得られること | 代わりに気をつけること |
| --- | --- | --- |
| 低く跳ぶ | 小さな凹凸で失う速度を減らす | 遅すぎる踏み切りでは段差に当たる |
| 高く跳ぶ | 高所の報酬や上段の足場に届く | 地上の燃料を飛び越す。着地で減速しやすい |
| 地面を走る | 下りの加速を使い、地上のアイテムを拾う | 荒れた場所では揺れや減速を受ける |

ジャンプは押した瞬間に出る。高く跳ぶために長時間その場で溜める方式にはしない。初期車両から低いジャンプと高いジャンプを使える。

連続ジャンプだけが有利になることを避けるため、ジャンプには少量の燃料を使い、高いジャンプほど消費を増やす。燃料表示を大きく減らす罰にはせず、平地での連打が長距離走行では不利になる程度にする。着地して車体が落ち着く短い時間を経て再び跳べる。

入力は踏み切り直前・着地直前のわずかなずれを許容する。押したのに出なかったと感じる場面を減らし、押しっぱなしで自動的に連続ジャンプはしない。

### 3.3 着地を気持ちよくする

地面に沿った角度で、強く叩きつけずに着地すると「ナイス着地」。速度を保ち、サスペンションが沈んで戻る動き、短い砂煙、明るい音、少量のコインで成功を伝える。

失敗した着地では速度が落ち、車体が一度大きく揺れる。通常の着地で何秒も跳ね続けたり、毎回転倒したりはしない。空中回転の回数は主な得点源にせず、坂道をきれいにつなぐ走りを報いる。

ナイス着地から余分な推進力を無制限に生まない。同じ場所で跳び続けてコインを稼ぐこともできないよう、新しい地点への移動を伴う着地だけを報酬対象にする。

### 3.4 燃料の調整方針

- アクセルを踏み続けると多く消費し、惰性走行中の消費は大きく減る。停止していても少量は減る。
- 初期タンクは全開走行で約45〜55秒分を目安とする。
- 基本ルートの燃料缶は、標準的な走行で約20〜30秒ごとに届く位置から調整する。
- 草原では、アクセルを踏み続けて大きく跳ぶ走りより、地形を読んだ走りのほうが明確に先へ進めるようにする。
- 熟練者は初期車両でも草原を完走できる。一方、初心者は数回の強化によって完走が近づく状態を狙う。
- タンクが大きくなると出走時の燃料が増える。通常の燃料缶の回復量は固定し、タンク強化だけで道中の補給量まで際限なく増える構造にはしない。
- 必要な燃料を取り損ねた直後に必ず終了する配置にはしない。少なくとも序盤は、次の補給まで立て直せる余裕を作る。

## 4. ステージとアイテムの配置

### 3地域の役割

| 地域 | 主な地形 | 新しく覚える楽しさ | 落とし穴の目安 |
| --- | --- | --- | --- |
| 草原の丘 | 大きく滑らかな坂、小さな段差、短い凹凸 | 惰性走行、低いジャンプ、着地 | 1か所。初めての穴は開始から約1分以降 |
| 赤岩の峡谷 | 深い谷、連続する起伏、短い上段の足場 | 勢いの連携、報酬を取る高さの選択 | 2か所程度 |
| 雲上の高原 | 長い登り、大きな下り、リズムが変わる複合地形 | 燃料配分と操作の総合判断 | 2〜3か所程度 |

後半の難しさは、坂の組み合わせや燃料管理から作る。穴を増やすことや、ひたすら急な坂にすることを難度上昇の主軸にしない。

### 地形の作り方

初回完成版の3地域は、走りの流れを調整した固定コースにする。毎回の挑戦で地形を覚え、前回の失敗を改善できることを優先する。

一つの地域を約15〜25秒の地形区間に分け、「下りで加速→荒れ地→着地」「大きな丘→補給」「高所報酬→穏やかな道」のような短い遊びを組み合わせる。山の高さだけを乱数で並べる方式にはしない。

- 基本ルートの燃料位置と危険地点は固定する。
- コイン列や一時アイテムは、成立を確認した少数の配置パターンで変化させる。
- 緊張する地形の後には、数秒間落ち着ける見通しのよい道を置く。
- 高いコイン列は踏み切りと着地点の手がかりにもする。必須の燃料は基本ルートで取れる位置に置く。
- 上段の足場は任意の短い寄り道にとどめる。失敗したら下の本道へ降りられる場所を多くし、報酬狙いが毎回即死の賭けにならないようにする。

### 落とし穴の扱い

穴は時々リズムを変えるアクセント。手前に目印と助走を置き、最大強化・ターボ中でも、危険を判断して入力する猶予を約2秒確保することを目標とする。ジャンプ前に穴の幅と向こう岸が分かる見せ方にする。

必須の穴は、初期車両の通常の進入速度とジャンプで余裕をもって越えられる幅にする。ジャンプ強化を買うまで越えられない穴や、丘の陰から突然現れる穴は設けない。燃料不足などで速度を失ったまま突っ込めば落ちるため、判断の意味は残る。

### 拾うアイテム

| アイテム | 効果 | 配置の意図 |
| --- | --- | --- |
| コイン | 持ち帰って車を強化 | 基本道にも置く。高所のまとまった列は任意の挑戦 |
| 燃料缶 | 燃料を一定量回復。最大値を超えない | 走行継続の中心。基本ルートで取得できる |
| マグネット | 約8秒、近くのアイテムを引き寄せる | コイン列をまとめて取る快感。地形の裏や大きく離れた足場からは吸わない |
| ターボ | 約4秒、アクセル中の加速を助ける | 開けた道を一気に走る快感。ブレーキで加速を抑えられる |

ターボは操作を奪う強制加速にしない。空中で勝手に飛距離が大きく伸びる作用を避け、穴の直前などに無造作に置かない。強化や一時効果が重なった最大速度でも、安全に判断できる画面とコースにする。

## 5. 繰り返す動機と恒久強化

### 成長は三つを組み合わせる

- **数秒の達成感**：きれいな着地、コイン列の回収、坂を勢いのまま越える。
- **数回の出走の目標**：前回止まった場所を越える、部品を一段強化する、地域を初めて完走する。
- **まとまった時間の目標**：次の土地を開く、車の見た目を育てる、3地域を踏破する。

「失敗してコインを稼ぐ」だけでなく、出走前に一つ、具体的な目標が分かるようにする。初完走前なら次の目印までの距離、完走後なら最高記録や未達成のコース課題を見せる。

### 強化は4系統・各5段階

| 強化 | 主な効果 | プレイ中に分かる変化 |
| --- | --- | --- |
| エンジン | 登坂力と再加速を上げる | 以前失速した坂を登れる。着地の失敗から戻りやすい |
| タイヤ | グリップを上げ、荒れ地での速度損失を減らす | 凹凸で止まりにくくなり、路面をつかむ |
| サスペンション | 着地の減速と揺れを抑える | 着地が安定し、次の坂につなぎやすい |
| 燃料タンク | 出走時の燃料と最大容量を増やす | 補給に届く余裕が増える |

最高速度の上昇は控えめにし、初期から最大強化でおおむね10〜15%増を調整の目安とする。強化により操作が難しくなったり、アイテムを拾えない速度になったりしないようにする。

強化は出走ごとのものではなく共通の車両に蓄積する。上位地域に行っても無効化しない。強化に合わせて既存コースを自動で難しくすることもしない。古い坂を楽に登れること自体が成長の報酬になる。

段階1・3・5ではタイヤ、サスペンション、タンク、車体装備の外見にも変化をつける。別の車を多数用意するより、一台への愛着を育てる。

### 補助パーツで得意分野を選ぶ

装備枠は一つ。パーツは到達実績で確定解放し、無料で付け替えられる。抽選や重複集めにはしない。

| パーツ | 解放の例 | 効果 |
| --- | --- | --- |
| 回収アーム | 草原の中間地点に初到達 | 通常のアイテム取得範囲が少し広がる |
| エコユニット | 草原を初完走 | 惰性走行時の消費をさらに抑える |
| ジャンプ補助 | 峡谷を初完走 | 長押しジャンプの高さを少し伸ばし、高所報酬を取りやすくする |

短押しジャンプの扱いやすさは、ジャンプ補助を付けても変えない。パーツは遊び方の好みを作るものであり、未装備では次の地域の必須ルートを進めない条件にはしない。

### 報酬と価格の初期案

通貨はコイン一種類にする。通常コイン、走行距離に応じた報酬、初到達・初完走の追加報酬が同じ財布に入る。

- 各系統の強化価格：120 → 240 → 450 → 750 → 1,200コイン。4系統すべての合計は11,040コイン。
- 通常の完走報酬の総額目安：草原120〜200、峡谷240〜380、高原420〜620コイン。初回報酬は別。
- 失敗時も取得済みのコインと、その時点までの距離報酬は全額確定する。
- 草原中間地点への初到達などには一度きりの追加報酬を置き、最初のまとまった出走で強化を一つ買える程度を狙う。
- 序盤は1〜2回、後半は2〜4回程度の出走で次の強化に届くことを目標にする。序盤ですぐ落下した場合まで、必ず強化を買える仕様にはしない。
- 難しい地域ほど同程度の進捗に対する報酬を上げ、上位地域の中間地点まで進めた挑戦が、下位地域の反復に劣りすぎないようにする。
- 初到達ボーナスは一度だけ。開始直後の終了を繰り返すより、先へ進むほうが時間あたりの報酬が良くなるよう調整する。

価格表だけで経済が成立したとは判断しない。実際の出走時間と取得量を見て、どれか一つの強化だけが必須になっていないか、待つためだけの周回が発生していないかを確認する。

### リザルトから次の出走へ

失敗画面は、到達地点、自己記録との差、今回得たコイン、次の目印までの距離を短く表示する。「あと何メートル」「あと何コイン」が分かるようにし、原因に応じて一つだけ簡単なヒントを出す。

再出走とガレージのボタンを大きく置く。記録更新演出や加算演出はタップで終えられ、再挑戦へ数秒で戻れる。強化のたびに複数画面を往復させない。

## 6. 初回体験と長く遊ぶ仕組み

### 最初の数回で起きてほしいこと

| 時期 | 体験の目標 |
| --- | --- |
| 最初の20秒 | 加速、サスペンションの揺れ、コイン回収が気持ちよい。安全な小段差でジャンプを覚える |
| 初回の中盤 | アクセルを離しても下りでは進むこと、燃料を拾うことを自然に覚える |
| 最初の失敗 | 何が起きたか分かり、途中で得た報酬が残る |
| 2回目 | 同じ坂を前より楽に越え、強化か走り方の改善を実感する |
| 3〜5回目前後 | 草原完走が見える。うまい人はこれより早く到達してよい |
| その後 | 新地域で地形と景色が変わり、同じ車でも別の走り方を試す |

長い説明画面を最初に読ませず、安全な場所で短い操作案内を一つずつ出す。初期状態からジャンプと姿勢補助を使えるようにする。

### 最大強化後

成長が続く時間は有限とする。まず3地域踏破までおおむね45〜90分程度の進行体験を目標に置き、最大強化の完了は個人の進み方によって前後する。

各地域には、完走・コイン回収・燃料を残して到着などの任意のメダル目標を用意する。メダルは新地域への入場条件にはせず、追加報酬や車体色の解放につなげる。

3地域踏破後には遠征モードを解放する。完成した地形区間を組み替えて、走行距離の記録へ挑む。同じ条件を再挑戦できるよう、直前のコース配置でも再走できるようにする。

遠征は単なる無制限の乱数地形にはしない。区間の入口速度、終端の高さ、必要なジャンプ後の着地、燃料の間隔がつながる組み合わせを使う。難度は地形の連携と補給間隔で緩やかに上げ、越えられない穴を出して強制終了させない。

遠征を増やすのは3地域の走行が仕上がってから。固定コースのタイム更新と回収目標だけでも再挑戦できる状態を先に完成させる。日課、ログインボーナス、待ち時間による足止めは設けない。

## 7. グラフィックと音の完成基準

方向性は、明るい2Dイラスト調のオフロード旅行。主役は黄色を基調にした小さなバギーとし、青緑などの差し色を使う。写実性よりも形の魅力、画面の統一感、動きの手応えを優先する。

「一般的なフリーゲーム相当」は幅があるため、初回完成版では次を具体的な到達基準とする。

| 対象 | 完成基準 |
| --- | --- |
| 車 | 車体・前後輪・サスペンションが別々に動く。加速で後ろに荷重がかかり、ブレーキで前が沈む。主役として見分けられる形と陰影がある |
| 道 | 接地する輪郭が明確。草、土、岩、地層の厚みがあり、装飾を足場と見間違えない |
| 背景 | 遠景・中景・近景の視差。地域ごとの配色とランドマーク。走行路付近は描き込みを整理する |
| エフェクト | 接地時の砂煙、着地の衝撃、回収時の粒子、ターボの軌跡を場面に合わせて使う。画面を覆わない |
| カメラ | 車をやや左に置いて進行先を広く見せる。小さな地面の揺れには追従しすぎず、坂と速度に合わせて視線を先へ送る |
| UI | 燃料、地域内の進捗、今回のコインがすぐ分かる。ボタン、文字、アイコンの見た目を統一する |
| ガレージ | 車を大きく見せ、強化前後の差が数字と外観で分かる。購入できるもの、解放条件が明確 |
| 音 | エンジン音が加速と負荷に反応する。接地、ジャンプ、着地成功、回収で異なる音を使う。音量調整とミュートがある |

燃料が少なくなったときは、ゲージ色と短い音で伝える。次の燃料までの距離も補助表示する。常時大量の数字を並べない。

背景や車の描き込みだけで完成度を上げようとせず、「操作→車の動き→エフェクト→音」が同時に返ることを重視する。画面揺れは弱めを標準とする。

## 8. 初回完成版の範囲と制作順

### 初回完成版に含めるもの

- 主役の車1台。4系統の恒久強化と、外観の段階変化。
- 固有の景色と走り方がある3地域。
- アクセル、ブレーキ、ジャンプ、穏やかな姿勢補助、自動復帰。
- コイン、燃料、マグネット、ターボ。
- 補助パーツ3種類、地域解放、任意のメダル目標、自己記録。
- タイトル、地域選択、ガレージ、リザルト、操作・音設定。
- 自動保存と、セーブの書き出し・読み込み。継続プレイを止めないために入れる。
- 3地域の完成後に、既存の地形を利用した遠征モードを仕上げる。

### 制作順と合格条件

| 順序 | 作る範囲 | 次へ進む基準 |
| --- | --- | --- |
| 1 | 30〜60秒の草原コースと車の操作。主役の絵と着地音も早く入れる | 強化や報酬がなくても、下り・ジャンプ・着地を繰り返したくなる |
| 2 | 草原全体、燃料とアイテム、失敗からの再挑戦 | ゲームオーバーの原因が分かり、走り方を変えて改善できる |
| 3 | 強化、リザルト、地域解放、保存 | 最初の数回で変化が分かり、次に遊ぶ目的が見える |
| 4 | 峡谷と高原、補助パーツ、画面と音の仕上げ | 色違いではなく、走り方が変わる。最大強化でも操作が破綻しない |
| 5 | メダル、遠征、全体の数値調整 | 成長が落ち着いた後も、操作と記録で再挑戦できる |

最初の段階が面白くなければ、ステージ数や強化項目の追加で埋め合わせず、加速、揺れ、ジャンプ、着地、地形間隔を調整する。

## 9. 制作時に重点的に確かめること

詳細な網羅テストではなく、次の不確実性を優先して解消する。

1. アクセル押しっぱなし・ジャンプ連打より、地形に合わせた操作が気持ちよく、有利になっているか。
2. 初期車両がわざと不快にされておらず、最初から一通り操作を楽しめるか。
3. エンジンや足回りの強化も体感でき、タンクだけが正解になっていないか。
4. 穴を最大速度でも認識して避けられ、穴への落下が失敗の大半を占めていないか。
5. 上位地域に挑むより、序盤で短い稼ぎを繰り返すほうが得になっていないか。
6. 一番強い車・ターボ・補助パーツが重なっても、入力、着地、アイテム回収が成立するか。
7. 進行不能、地面抜け、タッチ入力の固着、報酬や保存の消失がないか。

これは机上の仮説を遊べる品質へ近づける確認であり、コード品質のための整理や網羅的なテストとは分けて扱う。
