# COAST RUSH

海沿いの街を走る、3レーンの3Dエンドレスラン。iPad / iPhone Safari向け。縦・横画面に対応。

## 遊びの中心

コインの道を追い、切り返し・ジャンプ・スライドをつなぐと、身体の動きと音と光が応え、無敵のラッシュへつながる。

- 左右スワイプ: 1レーン移動。指が閾値を越えた時点で反応。
- 上スワイプ: ジャンプ。下スワイプ: スライド、空中では急降下。
- キーボード: 矢印 / WASD、スペースでジャンプ。P / Escapeで一時停止。
- オレンジの柵: 飛び越える。青いゲート: くぐる。電車: 左右に避ける。
- コイン回収と成功した回避でFLOWが増加。満タンで7秒間のラッシュ。
- ラッシュは無敵、障害物破壊、全レーンのコイン吸引、速度・視野・軌跡・音楽の変化。
- ラッシュ終了後は2秒保護。接触で1ライフ消費、3回目で終了。通常の接触では速度を落とさない。
- 初回は入力を待つ操作練習。練習はスキップ・再実行可能。
- ベスト距離、スコア、練習完了、音設定をlocalStorage `coast-rush-v1` に保存。

## 表現

参考: [Subway Surfers公式](https://subwaysurfers.com/) と公式ストア画面。3レーンの読みやすさ、コインの誘導、鮮やかな立体表現を参考にし、キャラクター・街・音は独自に制作。

クリーム・コーラル・青緑の海辺の街。帽子とバックパックを持つランナー、関節アニメーション、着地の変形、粒子、軌跡。キャラクターと障害物の影は毎フレーム更新。負荷による演出停止・影固定は行わない。背景ジオメトリは材質別に統合し、コインと粒子はインスタンス描画、障害物は再利用する。

## 構成と実行

ビルド不要。HTTPでこのフォルダを配信する。実行時にCDN・画像・音声を取得しない。Three.jsはMITライセンスでvendorに同梱。図形はThree.jsで制作し、音楽と効果音はWeb Audioで合成。

- `core.mjs`: 生成、移動、接触、スコア、練習
- `view.mjs`: 3D表示、モデル、エフェクト
- `audio.mjs`: 音楽、効果音
- `app.mjs`: タッチ、画面、保存、固定時間刻み
- `core.test.mjs`: 判定とコース生成の検証

```sh
node --test games/coast-rush/core.test.mjs
python3 -m http.server 8000
```

PWA用メタ情報・manifestあり。サービスワーカーは使用しない。初回読み込みにはネットワークが必要。

## 検証範囲

コードの構文、コース生成の安全経路、ジャンプ・スライド・接触、ラッシュ開始と終了保護、チュートリアル、複数シードでの連続走行を自動検証。ブラウザでの操作感、実機フレームレート、iOSのホーム画面起動はユーザーの試遊で確認する。
