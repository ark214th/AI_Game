# ふしぎな ペットホテル

小学1年生向けの「お世話＋かざりつけ」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

ゲーム一覧（トップの `index.html`）から公開中（2026年9月30日公開）。

## 遊び方

1. ベルが鳴ると、カバンを持ったお客さんがロビーに来て、希望を言う（「うみ🐚みたいな へやが いいな」など）。
2. お客さんを指で空いている部屋まで運ぶ（または、お客さんをタッチ → 部屋をタッチ）。好きなかざりがある部屋だと喜ぶ。**好きなものが全部そろった部屋**だと「だいすきな へや！」で特別に喜ぶ（ハート+2）。
3. 部屋の中で、光っているボタンを押してお世話する（1匹につき3つ＋最後に ねんね）。
   - 🍽️ ごはん：お皿の4つから選んで口まで運ぶ。好きなもの・苦手なものがある。
   - 🫧 おふろ：こすって泡立てる → シャワー → タオル。
   - 🤲 なでる：喜ぶ場所がある。
   - ⚽ あそぶ：ボール（取ってくる）か しゃぼんだま。好きなあそびがある。
   - 🎀 おしゃれ：リボン・はなかんむり・ほしのピン・はっぱのぼうし・マフラー・かいがらのピンから選んで頭にのせる。帰るまでつけている。好きなものがある。
   - **その子だけのお世話**（ボタンの絵がお客さんごとに変わる）
     - ふわり：🧶 ブラシで もこもこ
     - ごろた：🔄 横にシュッと ころころ
     - ぽかり：🔥 しっぽの近くをトントン、ふーふー
     - ちゃぷ：🐚 かいがらを3つ さがす
     - ぽぷり：🌷 じょうろで みずやり
     - きらら：⭐ しっぽの ほしを みがく
     - ぷるるんゼリー：🍦 あたまを トントンして クリームを のせる
     - くもくもさん：🌟 ひかった ほしを 5つ かぞえる
     - おおきなカニ：✌️ じゃんけん 3かい
     - いたずらかぜ：🌀 かざぐるまを ぐるぐる まわす
   - 🌙 ねんね：ベッドへ移動したら、やさしくトントン5回。ベッドがあると ぐっすり。
4. 1匹めのお世話が1つ終わると、2匹めがやってくる。部屋の画面の右上の顔をタッチすると、その子の部屋へ移れる。
5. 「🎨 かざる」で家具を運ぶ・しまう、かべがみ・ゆかを変える。**置いた家具をタッチすると色が変わる**（ベッド・ソファ・ラグ・クッション・まど など）。
6. 全員が眠ると「🌙 おやすみ」→ 朝にお客さんが手をふって帰り、おてがみ（感想・次のヒント・おみやげ）を残していく。
7. ハートで部屋が増える（最大9部屋）。ホテルは2階建てのまま横に広がり、指で左右に動かして見る。

## しくみ

- 1日のお客さんは2匹で、1匹ずつ来る。部屋が増えても人数は増えない（忙しくならない）。時間制限なし。
- 好きなかざりのしるし：☁️くも・💧みずいろ・⭐ほし・🪨いわ・🌿みどり・🎀ピンク・🔥あったか・🐚うみ・🌸おはな・🌙よる。
- わかったくせ（食べもの、あそび、おしゃれ、なでる場所、おふろ、好きなかざり）は「ずかん」に、もらったおてがみは「おてがみ」に残る。
- ゲームオーバーなし。画面の字は ひらがな・カタカナ だけ（ことばの間のスペースで改行する）。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下にテスト用のボタンが出る（ハート+10、きょうのお客さんを全員あんないしてお世話を終わらせる、保存データの消去）。

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない（絵は Canvas 2D の図形、音は Web Audio で合成）。

- `data.mjs`：お客さん・食べもの・あそび・おしゃれ・その子だけのお世話・家具（色がえの色）・かべがみ・ゆかのデータ
- `core.mjs`：来客（新しい子・大きなお客さんの日）・チェックイン・お世話・かざりの反応（全部そろうボーナス）・色がえ・おてがみ・おみやげ・部屋とスイートの増築・保存データの整形（画面と切り離した計算）
- `draw.mjs`：いきもの（8種＋ぷにゅ）・おしゃれ・部屋・家具・ホテルの絵
- `app.mjs`：画面の切りかえ、タッチ操作（お世話のミニゲーム・かざりつけ）、保存（localStorage `fushigi-pet-hotel-v1`）
- `audio.mjs`：効果音とBGM
- `core.test.mjs`：`node --test games/fushigi-pet-hotel/core.test.mjs`。1匹ずつ来て1日を最後まで遊べること、チェックイン（ほかの子がいる部屋に入れない・好きな部屋で喜ぶ）、食べもの・あそび・ベッドの好み、おてがみの内容、部屋が最大まで増えること、おみやげが全部そろうこと、おしゃれ・その子だけのお世話、新しい子が順に来ること、スイートと大きなお客さん、色がえ、お皿の食べもの、保存データの読み直し（前の版のデータも読める）、データに漢字がないことなどを確認
