# ふしぎな ペットホテル（試作）

小学1年生向けの「お世話＋かざりつけ」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

**試作段階のため、ゲーム一覧（トップの `index.html`）からはまだリンクしていない。** `games/fushigi-pet-hotel/` を直接開いて遊ぶ。

## 遊び方

1. ホテルの断面図で、ふきだしが出ている部屋をタッチする。
2. 部屋の中で、光っているボタンを押してお世話する。
   - 🍎 ごはん：お皿の食べものを、指で口まで運ぶ。好きなもの・苦手なものがある（苦手なものは食べないだけで、失敗にはならない）。
   - 🫧 おふろ：体をこすって泡立て、汚れを落とす → シャワーを指で動かして泡を流す。
   - 🤲 なでる：体を指でなでる。喜ぶ場所（あたま・ほっぺ・おなか）がある。
3. 「🎨 かざる」で、家具を指で運んで置いたり、かべがみ・ゆかを変えたりできる。家具を下の引き出しにもどすと片づく。
4. 全員のお世話が終わると「🌙 おやすみ」が出る → 朝にお客さんからおみやげ（家具・かべがみ・ゆか）をもらえる。
5. ハートがたまると部屋が増える（10・25・45 で、最大5部屋）。

## しくみ

- お客さんは1日2匹。部屋が増えても人数は増えない（忙しくならない）。
- お客さんには好きなかざりのしるし（☁️くも・💧みずいろ・⭐ほし・🪨いわ・🌿みどり）がある。好きなものがある部屋に優先して泊まり、到着時と、かざりを足したときに喜んでハートをくれる。
- わかったくせ（好きな食べもの・苦手な食べもの・なでると喜ぶ場所・おふろの好き嫌い・好きなかざり）は「ずかん」に書かれる。
- ゲームオーバー・時間制限はない。画面の字は ひらがな・カタカナ だけ。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下にテスト用のボタンが出る（ハート+10、全員のお世話を終わらせる、保存データの消去）。

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない（絵は Canvas 2D の図形、音は Web Audio で合成）。

- `data.mjs`：お客さん・食べもの・家具・かべがみ・ゆかのデータ
- `core.mjs`：お世話・かざりの反応・1日の流れ・おみやげ・部屋の増築・保存データの整形（画面と切り離した計算）
- `draw.mjs`：いきもの・部屋・家具・ホテルの絵
- `app.mjs`：画面の切りかえ、タッチ操作（お世話のミニゲーム・かざりつけ）、保存（localStorage `fushigi-pet-hotel-v1`）
- `audio.mjs`：効果音とBGM
- `core.test.mjs`：`node --test games/fushigi-pet-hotel/core.test.mjs`。1日を最後まで遊べること、食べものの好き嫌い、なでる場所の判定、好きなかざりの部屋に泊まること、家具の数の制限、部屋が最大まで増えること、おみやげが全部そろうこと、保存データの読み直し、データに漢字がないことなどを確認
