# ふしぎな ペットホテル（開発中）

小学1年生向けの「お世話＋かざりつけ」ゲーム。iPhone・iPad の横持ち（Safari）向け。企画は [DESIGN.md](DESIGN.md)。

開発中のため、ゲーム一覧の通常の欄には載せていない。トップページの開発者モード（タイトルを5回タップ）で表示される「開発中・非掲載」から開く。

## 遊び方

1. ベルが鳴ると、カバンを持ったお客さんがロビーに来る。ふきだしで「くも☁️の ある へやが いいな」など希望を言う。
2. お客さんを指で空いている部屋まで運ぶ（または、お客さんをタッチ → 部屋をタッチ）。好きなかざりがある部屋だと喜んでハートをくれる。ない部屋でも失敗にはならず、ちょっとさみしそうにするだけ。
3. 部屋の中で、光っているボタンを押してお世話する（1匹につき3つ＋最後に ねんね）。
   - 🍽️ ごはん：お皿の食べものを指で口まで運ぶ。3口で食べ終わる。好きなもの・苦手なものがある。
   - 🫧 おふろ：こすって泡立てる → シャワーで流す → タオルでふく。
   - 🤲 なでる：体を指でなでる。喜ぶ場所（あたま・ほっぺ・おなか）がある。
   - ⚽ あそぶ：ボール（投げると取ってくる、3回）か しゃぼんだま（ふくと ぴょんと割る、6こ）を選ぶ。好きなあそびがある。
   - 🌙 ねんね：ベッドへ移動したら、やさしくトントン5回で眠る。ベッドがあると ぐっすり（ハート2）。
4. 1匹めのお世話が1つ終わると、2匹めがやってくる。部屋の画面の右上にお客さんの顔が並び、タッチでその子の部屋へ移れる（ロビーで待っている子には🛎️が付く）。
5. 「🎨 かざる」で、家具を指で運んで置いたり、かべがみ・ゆかを変えたりできる。好きなかざりを置くと「〇〇、だいすき！」と喜ぶ。
6. 全員が眠ると「🌙 おやすみ」が出る → 朝にお客さんがロビーから手をふって帰り、おてがみ（感想とおみやげ）を残していく。おてがみには「こんどは ほし⭐の ある へやだと うれしいな」のような次のヒントも書かれる。
7. ハートがたまると部屋が増える（12・30・55・85・120・160・205 で、最大9部屋）。ホテルは2階建てのまま横に広がり、入りきらないときは指で左右に動かして見る。増築は足場の工事の演出つき。

## しくみ

- 1日のお客さんは2匹で、1匹ずつ来る。部屋が増えても人数は増えない（忙しくならない）。時間制限なし。
- お客さんの好きなかざりのしるし：☁️くも・💧みずいろ・⭐ほし・🪨いわ・🌿みどり。
- わかったくせ（好きな・苦手な食べもの、好きなあそび、なでると喜ぶ場所、おふろ、好きなかざり）は「ずかん」に、もらったおてがみは「おてがみ」に残る。
- お客さんはときどき独り言を言い、部屋に入ると好きな家具の名前を挙げて感想を言う。
- ゲームオーバーなし。画面の字は ひらがな・カタカナ だけ（ことばの間のスペースで改行する）。

## テストプレイ用

URL の末尾に `?debug` を付けると、画面の下にテスト用のボタンが出る（ハート+10、きょうのお客さんを全員あんないしてお世話を終わらせる、保存データの消去）。

## 構成

ビルド不要。フォルダをそのまま HTTP で配信すれば動く。外部のCDN・画像・音声は使わない（絵は Canvas 2D の図形、音は Web Audio で合成）。

- `data.mjs`：お客さん・食べもの・家具・かべがみ・ゆかのデータ
- `core.mjs`：来客・チェックイン・お世話・かざりの反応・おてがみ・おみやげ・部屋の増築・保存データの整形（画面と切り離した計算）
- `draw.mjs`：いきもの・部屋・家具・ホテルの絵
- `app.mjs`：画面の切りかえ、タッチ操作（お世話のミニゲーム・かざりつけ）、保存（localStorage `fushigi-pet-hotel-v1`）
- `audio.mjs`：効果音とBGM
- `core.test.mjs`：`node --test games/fushigi-pet-hotel/core.test.mjs`。1匹ずつ来て1日を最後まで遊べること、チェックイン（ほかの子がいる部屋に入れない・好きな部屋で喜ぶ）、食べもの・あそび・ベッドの好み、おてがみの内容、部屋が最大まで増えること、おみやげが全部そろうこと、保存データの読み直し（前の版のデータも読める）、データに漢字がないこと、ごはんのふきだしが食べものの絵でないことなどを確認
