# ふしぎな ペットホテル 企画メモ

作成日：2026年9月30日
状態：公開（2026年9月30日。お子さんのプレイで気に入ったのを確認してゲーム一覧に掲載）。M2：お客さん6種＋大きなお客さん2種（すべて動物モチーフ）・お世話6種＋その子だけのお世話・スイートルーム・色がえ・テーマそろえ。
想定プレイヤー：小学1年生（ひらがな・カタカナが読める。漢字は読めない）。
想定環境：iPhone・iPad の横持ち、Safari。

## 目指す体験

**ふしぎな生きものが泊まりに来るホテルで、お世話をして、部屋をかわいく飾る。飾った部屋を気に入ったお客さんが来てくれる。**

1. お世話が主役：さわって気持ちいい（ぷにっと弾む、泡がふえる、なでると目を細める）。
2. 忙しくしない：1日のお客さんは2匹まで。時間制限なし。失敗なし。
3. 飾りつけが遊びとつながる：お客さんには好きなかざりがあり、合う部屋だと喜ぶ。
4. 発見がある：好きな食べもの・なでる場所・好きなかざりを試して見つけ、ずかんが埋まる。

## 遊びの流れ

```
おせわする → ハート・おみやげ（家具）
   ↑                      ↓
あたらしい お客さん ← へやを かざる／へやが ふえる
```

- ステージ選択はなく、ホテルの保存データ1つで続いていく。
- 1日：朝お客さんが来る → お世話3つ（順番はランダム、1つずつふきだしで出る） → 全員満足で「おやすみ」 → 朝におみやげ。

## M2 で足したこと

保護者と相談して、ペットを育てる要素はやめ、「毎日の新しさ」（お客さん・飾り・お世話の種類）に力を入れた。お子さんが ぷにゅを「ハムスター」と思っていることから、お客さんは全員「丸いからだに動物の耳やしっぽ」の ふしぎな動物にそろえた。

- お客さん：ふわり（くもの ひつじ）・ごろた（こけの かめ）に見た目を変更。ぽかり（ほのおの きつね）・ちゃぷ（うみの ラッコ）・ぽぷり（はなの はりねずみ）・きらら（ほしの ねこ）を追加。ホテルが大きくなると順に来る。
- 大きなお客さん：どらりん（ドラゴンの あかちゃん）・くーちゃん（くじらの こ）。ハート70で「スイートルーム」（2部屋×2階ぶん）ができ、3日に1回来る。
- お世話：🎀 おしゃれ（6種）と、その子だけのお世話（ブラシ・ころころ・ふーふー・かいがらさがし・みずやり・ほしみがき）。
- 飾り：しるしを4つ追加（🔥あったか・🐚うみ・🌸おはな・🌙よる）。家具14種・かべがみ3種・ゆか3種を追加。置いた家具をタッチすると色が変わる。好きなものが全部そろうと「だいすきな へや！」。
- ごはんは7種類から、毎回4つがお皿にのる（好きなもの・苦手なものは必ず入る）。

## M3：ぷにゅランドの ともだち（2026年10月2日）

お子さんが各キャラを10回以上お世話して「キャラを増やしてほしい」「きらきらランドのボスに来てほしい」と要望。「ぷにゅの きらきらランド」のボス5体をお客さんにした。

- ぷるるんゼリー（クリームのせ）・くもくもさん（ほしかぞえ、ナイトキャップ）・おおきなカニ（じゃんけん）・いたずらかぜ（かざぐるま）。部屋が7〜8つで来はじめる。
- でかもやもやは名前どおり「おおきな お客さん」としてスイートへ。おみやげは「おうさまの いす」。
- 🍰 おかしの しるし、家具（ケーキの いす・キャンディの ランプ・たからばこ・かざぐるま）、かべがみ「おかし」・ゆか「チョコ」、食べもの（プリン・ドーナツ・おにぎり）を追加。
