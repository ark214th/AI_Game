# ふしぎな ペットホテル 企画メモ

作成日：2026年9月30日
状態：試作（M0）。お客さん2種・お世話3種・かざりつけ・1日の流れ・部屋の増築まで。
想定プレイヤー：小学1年生（ひらがな・カタカナが読める。漢字は読めない）。
想定環境：iPhone・iPad の横持ち、Safari。

## 目指す体験

**ふしぎな生きものが泊まりに来るホテルで、お世話をして、部屋をかわいく飾る。飾った部屋を気に入ったお客さんが来てくれる。**

1. お世話が主役：さわって気持ちいい（ぷにっと弾む、泡がふえる、なでると目を細める）。
2. 忙しくしない：1日のお客さんは2匹まで。時間制限なし。失敗なし。
3. 飾りつけが遊びとつながる：お客さんには好きなかざりがあり、合う部屋だと喜ぶ。
4. 発見がある：好きな食べもの・なでる場所・好きなかざりを試して見つけ、ずかんが埋まる。

## 遊びの流れ

```
おせわする → ハート・おみやげ（家具）
   ↑                      ↓
あたらしい お客さん ← へやを かざる／へやが ふえる
```

- ステージ選択はなく、ホテルの保存データ1つで続いていく。
- 1日：朝お客さんが来る → お世話3つ（順番はランダム、1つずつふきだしで出る） → 全員満足で「おやすみ」 → 朝におみやげ。

## お客さん（試作）

| | ふわり（くもの こ） | ごろた（いしころの こ） |
| --- | --- | --- |
| 好きな食べもの | 🍭 にじいろアメ | 🍪 いしころクッキー |
| 苦手な食べもの | 🍪 | 🍭 |
| なでると喜ぶ | ほっぺ | あたま（こけ） |
| おふろ | ちょっと にがて（シャワーで ふくらむ） | だいすき |
| 好きなかざり | ☁️ くも・💧 みずいろ・⭐ ほし | 🪨 いわ・🌿 みどり |

## このあと（案）

- お客さんを増やす（フロアごとに新しい子。例：ほのおの子、うみの子、ほしの子）。
- お客さんが置いていく たまご を「わたしのへや」で育てる（ごはんの色で姿が変わる）。
- 大きなお客さん（ドラゴンの赤ちゃん等）がときどき泊まりに来る。
- 家具・かべがみを増やす。家具の向きを変える。
- ねかしつけ（子守歌）のお世話。
- お子さんの反応を見て、ハートの量・部屋が増えるペースを調整する。
