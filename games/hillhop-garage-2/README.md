# HILLHOP GARAGE 2

加速して谷を跳び越え、空中の燃料を取り、次の下りへの着地をつなぐ坂道ドライブゲーム。iPad Safari横向き、キーボードにも対応。画像・音は元のゲームのcanvas描画とWeb Audioを複製して使用しています。外部依存なし。

- 公開先: https://ark214th.github.io/AI_Game/games/hillhop-garage-2/
- 旧版: https://ark214th.github.io/AI_Game/games/hillhop-garage/

## 操作

アクセルは右矢印 / D、ブレーキは左矢印 / A、ジャンプは Space / 上矢印。タッチでは画面下のボタンを同時押しできます。

黄色い帯の前で助走し、帯の中でジャンプ。長押しで高く、短押しで低く飛びます。空中ではアクセルを離し、青緑の下り斜面へ着地してください。遅すぎると向こうの登りへ衝突し、早すぎ・高すぎでも狙いが外れます。必要なら空中でブレーキを使って鼻先を下げられます。

角度がよく合うと「JUST!」と専用の音・光が出て、一気に加速します。少しずれた成功は「GOOD」、斜めにぶつかると「CRASH!」で強く減速します。成功の連続数はFLOWとして表示します。谷底の地上経路は安全ですが、時間と燃料がかかります。空中の燃料は10、地上の小補給は8。ジャンプの追加燃料消費はありません。

## 旧版との分離

旧版のフォルダと動作は変更していません。「2」は新規セーブから開始し、localStorageの `hillhop-garage-2-v1` に保存します。書き出し名は `hillhop-2-save.json`。識別子が異なる旧版のセーブファイルは直接読み込みません。

同じブラウザで旧版を遊んでいた場合は、設定の「旧版の車をコピー」からコイン・強化・装備をコピーできます。「2」のこれらの値を置き換えますが、旧版には書き込まず、「2」のコース記録も保持します。車の性能やパーツの効果はこの版のルールが適用されます。

## 着地と地形の更新（v2）

谷越え・ショートホップ・ロングフライト・段差ドロップ・二連リッジの5種類。地形の名前とコツは練習中に表示します。希少な落とし穴も小・大・段差の3形状です。燃料消費、タンク容量、強化価格は維持しています。新しい地形でもコイン・強化・解放・メダル・距離は引き継ぎ、以前のタイムは旧記録として保存します。

JUST着地の直後0.5秒間は、上り坂で重力・転がり抵抗・路面の曲がりによる減速を受けず、路面に沿った走行速度を保ちます。ブレーキと着地の衝突は従来どおり働きます。

## 峡谷・高原の専用コース（v3）

- ステージ2「赤岩の峡谷」：走行距離5,775m、18のジャンプ地形。赤岩スパンの長い谷越え、短押しでつなぐ連続ステップを追加。赤岩の入口 → 採掘場の連続段丘 → 夕映えの大峡谷。岩のアーチと採掘場の木組みを背景に追加しました。
- ステージ3「雲上の高原」：走行距離6,775m、19のジャンプ地形。長押しで乗り越える高台ジャンプ、短押しで下へ降りる雲海ダイブを追加。雲の登山道 → 雲海の尾根 → 天空の峠。雲海とロープウェイのゴンドラを追加しました。
- 各地域に区間の看板・走行中の案内を追加。穴は各2か所に留めています。エンドレスにも全9種類の地形が登場します。
- 草原の地形、燃料消費、強化価格・効果、JUST後0.5秒の上り坂保護は維持しています。
- 既存のコイン・強化・装備・解放・距離・メダルは引き継ぎます。変更したステージ2・3の従来のタイムだけ旧記録に移し、新コースのタイムを別に計測します。

ソース上の走行シミュレーションでは、新4地形それぞれで未強化の空中補給＋JUSTを確認。未強化・精密操作の完走は峡谷104秒（燃料26）、高原119秒（燃料はゴール前で尽きるが惰性で到達）。未強化・低速走行では約809m / 847mで燃料切れ。全Lv20の低速走行では両地域とも完走します。精密操作はコース情報を使う自動操作で、人間の操作感を保証するものではありません。ブラウザを使わない起動確認で両地域の描画呼び出しと区間表示を確認しました。


## 操作チュートリアル

初回の「走り出す」で練習を案内します（既存セーブでも、この案内は一度だけ表示）。スキップ可能で、メニューの「操作を練習する」からいつでも再開できます。

助走 → ジャンプ → アクセルとジャンプを離す → 姿勢を合わせる → 青緑への着地、の5段階。踏み切りと説明中は時間を止め、押すボタンを強調します。姿勢の練習では青緑の線を目標にブレーキを操作し、着地は0.4倍速で練習。失敗時は踏み切りから再開できます。成功後は通常速度・停止なしの練習も選べます。

練習車は未強化・装備なしで、燃料切れ・穴・進行報酬はありません。実際の走行・姿勢制御・着地判定を使います。既存の車、コイン、解放状況、記録、出走回数は維持し、案内済み／練習完了だけを保存します。

通常走行の説明札、繰り返しの操作ヒント、ジャンプボタン下の説明は削除。黄色の踏み切り帯・青緑の着地帯・穴の警告・燃料や成功演出は残しています。

`node games/hillhop-garage-2/tutorial-check.cjs` で段階の進行、説明中の停止、姿勢操作、JUST着地、失敗と再試行、停止なし練習、セーブ互換、報酬の分離を確認できます。既存のバランス確認も成功。ブラウザなしのUI確認で案内・スキップ・練習完了・一時停止・本番への復帰を確認。iPad実機での操作感・見た目の確認は未実施です。
