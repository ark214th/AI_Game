# HILLHOP GARAGE 2

加速して谷を跳び越え、空中の燃料を取り、次の下りへの着地をつなぐ坂道ドライブゲーム。iPad Safari横向き、キーボードにも対応。画像・音は元のゲームのcanvas描画とWeb Audioを複製して使用しています。外部依存なし。

- 公開先: https://ark214th.github.io/AI_Game/games/hillhop-garage-2/
- 旧版: https://ark214th.github.io/AI_Game/games/hillhop-garage/

## 操作

アクセルは右矢印 / D、ブレーキは左矢印 / A、ジャンプは Space / 上矢印。タッチでは画面下のボタンを同時押しできます。

黄色い帯の前で助走し、帯の中でジャンプ。長押しで高く、短押しで低く飛びます。空中ではアクセルを離し、青緑の下り斜面へ着地してください。遅すぎると向こうの登りへ衝突し、早すぎ・高すぎでも狙いが外れます。必要なら空中でブレーキを使って鼻先を下げられます。

角度がよく合うと「JUST!」と専用の音・光が出て、一気に加速します。少しずれた成功は「GOOD」、斜めにぶつかると「CRASH!」で強く減速します。成功の連続数はFLOWとして表示します。谷底の地上経路は安全ですが、時間と燃料がかかります。空中の燃料は10、地上の小補給は8。ジャンプの追加燃料消費はありません。

## 旧版との分離

旧版のフォルダと動作は変更していません。「2」は新規セーブから開始し、localStorageの `hillhop-garage-2-v1` に保存します。書き出し名は `hillhop-2-save.json`。識別子が異なる旧版のセーブファイルは直接読み込みません。

同じブラウザで旧版を遊んでいた場合は、設定の「旧版の車をコピー」からコイン・強化・装備をコピーできます。「2」のこれらの値を置き換えますが、旧版には書き込まず、「2」のコース記録も保持します。車の性能やパーツの効果はこの版のルールが適用されます。

## 確認

`node games/hillhop-garage-2/balance-check.cjs`

未強化の草原で、安全走行は約867m、不正確な狙いのジャンプは約3967m、地形に応じて押す長さを変える操作は4775mを完走。一定間隔のジャンプは衝突が増えて約863m。コース情報を使う理想的な操作を含み、人間の成功率や面白さを保証するものではありません。穴では各操作とも手前で加速してジャンプしています。

同じ進入速度600から、角度の合う着地は約775、少しずれた成功は約685、大きく角度を外した着地は約135へ変化することを確認。全5形状で空中補給とJUST着地が両立する軌道を確認しました。

全Lv20では安全走行で全3地域完走。セーブ識別、エンドレスの追加地形、JS構文を確認しました。ブラウザを使わないUIの起動確認ではメニュー、走行描画の呼び出し、設定、車のコピー、新版だけへの保存を確認しています。Safariでの画面と実際の操作感は未確認です。

詳細な体験の狙いと調整値は [DESIGN.md](DESIGN.md)。

## 着地と地形の更新（v2）

谷越え・ショートホップ・ロングフライト・段差ドロップ・二連リッジの5種類。地形の名前とコツを走行中に表示します。希少な落とし穴も小・大・段差の3形状です。燃料消費、タンク容量、強化価格は維持しています。新しい地形でもコイン・強化・解放・メダル・距離は引き継ぎ、以前のタイムは旧記録として保存します。

JUST着地の直後0.5秒間は、上り坂で重力・転がり抵抗・路面の曲がりによる減速を受けず、路面に沿った走行速度を保ちます。ブレーキと着地の衝突は従来どおり働きます。
